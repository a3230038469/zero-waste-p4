# P4 组 · 周复盘

> **每周日花 15 分钟**：把这一周过一遍。重点不是"做了什么"，而是"我因此变成了什么样"。
> 六周下来，这里就是你们组的成长年轮。管家起草 → 小志改。

---

## 模板（每周照这 6 栏填）

1. **这一周，我们走到哪一步了**（客观进度）
2. **技能上我学到/练到了什么**（AI、网页、做文档……）
3. **协作上我学到什么**（怎么跟人搭档、怎么表达、怎么处理分歧）
4. **关于我自己，我发现什么**（擅长什么、怕什么、想改什么）
5. **踩的坑 / 没解决的矛盾**
6. **下周重点（只写 3 件）**

## W1 组队培训｜9.14 - 9.20

**① 走到哪一步了**
- 完成：助教启动 → 方向主教培训 → 开营 → 进组 → 全员自我介绍 → 技术入门培训 → **破冰会（9.20 开完）** → 需求沟通培训
- 进行中：队名 / 口号投票、成员介绍与团队公约共创（**组内 deadline 周一 24:00**）、角色认领
- 待交：**《团队说明书》9.22 23:59**

**② 技能上（这一周摸到的新东西）**
- **WorkBuddy 跑通了**：装好、建项目、配飞书、连通性测试——这是后面所有活的地基
- 第一次用"**AI 先调研、再开会**"的方式带一个团队：机构情况、日程、角色、组员画像全提前备好，会上只做决定
- 学会**用投票代替争论**（队名、口号），比讨论半小时高效得多
- 拿到两个马上能用的方法论：**5 个为什么**、**6 层分析框架**

**③ 协作上**
- 我们组抢了两个"第一"：**第一个全员自我介绍的组**、**第一个把机构调研做完发群的组**（助教原话"进度非常超前"）
- 破冰会开成了高效型：**50 分钟内出结论，20 分钟内发群**
- 出现**第一个主动认领硬活的人**（调研负责人）——从"没人愿意当组长"到有人举手，这是好信号
- 遗留：机构伙伴还没进群 → 调研没法真正开始；瑞泽三天空缺

**④ 关于我自己**
- 做得最对的一件事：**没把"组长"理解成"什么都自己干"**——先把材料备齐、把节奏定好，让每个人只需要做决定
- 做得不够的：**跟梓柔那件事应该更早说**（营方建议她当组长，我先自荐了）→ 拖到开会前才处理，风险没必要
- 想练的表达，这周有进步：会上按流程主持、会后 20 分钟出结论，都没卡壳

**⑤ 踩的坑 / 未解决的**
- ~~机构伙伴至今没进群~~ → **9-20 22:06 机构老师「黄正」已进群**（晚了 4 天，但正好赶上 W2 访谈周）

- **群里部分同学只显示"用户XXXXXX"**（跨租户昵称限制）→ 认人得靠助教或会议里的昵称
- 瑞泽三天缺席 → 他的角色要留余地
- ⚠️ 遗留：**队名/口号还没投出来**（9-20 22:21 又重开了投票、加了新选项「宽益工坊」），周一 24:00 前要收口

**⑥ 下周重点（3 件）**
1. **周一晚前收齐**队名 / 口号 / 成员介绍 / 公约 / 角色 → 交掉《团队说明书》（9.22 23:59）
2. **推动机构伙伴进群 + 完成第一次需求访谈**（用 6 层框架拟提纲，用 5 个为什么追问）
3. 各角色动起来：调研先跑、技术先把环境搭好
