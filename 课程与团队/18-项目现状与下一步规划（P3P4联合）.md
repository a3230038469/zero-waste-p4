## 五、我的分工建议（今天两组会上用）

### 5.1 先说切法 —— 别按"你们做前端、我们做后端"切

9-24 会上定的原话是"**按功能模块拆分任务，每人负责单一模块**"。这个切法是对的，理由是硬的：

> **前后端之间唯一的接口就是"字段"。** 如果两组分开做前后端，字段名对不上就是白做一轮。按"功能模块"切，每个模块从数据到页面**一个人包到底**，接口风险直接归零。

### 5.2 建议拆成 7 个模块包

| 模块包 | 包含 | 能否独立开发 | 依赖 |
|---|---|---|---|
| **M1 数据底座** | 元数据字段定义 + 飞书多维表格建表 + 400+ 份数据导入 + 多标签 | ✅ | 等老师的 Excel 清单 |
| **M2 检索与浏览** | 书架式展示 + 文件名检索 + 类型/主题/年份筛选 + 排序 | ✅ | 字段定完就能开工 |
| **M3 预览与下载** | PDF 在线预览 + 直接下载 | ✅ | 同上 |
| **M4 登录与注册** | 登录门槛 + 注册 5 字段 + 隐私提示 | ✅ | 独立 |
| **M5 管理后台** | 文件增删改 + 用户提交审核 + **使用统计** | ✅ | 依赖 M1 字段 |
| **M6 AI 问答** ⚠️ | 知识切片 + 向量检索 + 角色设定调参 + 来源标注 | ✅ | ⚠️ 撞红线，先问助教 |
| **M7 上传与反馈页** | 用户上传表单 + 反馈提交页 | ✅ | 独立 |
