## 三、给普通成员的话术（开工时再发，配合教程）

> @成员
>
> 任务池上线了，开工前只看**一份**文档：《成果上GitHub-WorkBuddy全员交付教程》（在项目网盘 `公共资料/拼装协作/`）。
>
> 流程超简单：
> 1. **领任务**：GitHub 仓库 → Issues → 筛"待领取"，assign 自己+标签改"进行中"
> 2. **干活**：在咱们项目对话里让 Agent 干，把任务内容贴给它（教程里有现成的"标准交付指令"，复制就能用）
> 3. **交付**：下载文件 → GitHub 网页建分支 → 拖文件进去 → 点按钮发 PR。**全程零命令行**
>
> 三条红线记住：提交说明带 **#任务号**、只改自己任务的目录、**字段名照契约别自己发明**（Agent 会帮你把关）。
>
> 不会写代码的也有活：WeKnora 部署配置、内容整理、测试用例、文档，都有任务。卡住了直接在对话里问 Agent，它懂这套规则。

## 六、队友一定会问的问题（预备答案，被问到直接复制）

| 问题 | 你答 |
|---|---|
| **为啥要整 GitHub，WorkBuddy 里干不行吗？** | 干活还是在 WorkBuddy 里干，不变。GitHub 只是"拼装车间"——四组 20 多人的成果要合成一个产品，必须有地方管版本、防覆盖、能回退，这是全世界程序员协作的标准做法。而且 WorkBuddy 沙箱连不上 GitHub 的限制已经考虑进去了，教程就是按这个现实设计的。 |
| **我不会编程，能有我的活吗？** | 有。任务分好几种：写代码只是其中一类。WeKnora 引擎部署配置（照文档点点点）、400 份资料的内容整理、测试用例编写、验收检查、文档撰写，都是任务，一样领。 |
| **必须学 Git 吗？** | 不用。主推姿势是 GitHub 网页拖拽上传，零安装零命令。教程 4 步走完。以后想学再学（有进阶教程）。 |
| **WeKnora 是啥？靠谱吗？** | 腾讯 2025 年开源的企业级 RAG 框架（就是做"上传文档→AI 问答"的），MIT 许可证（随便用，公益项目无风险），Docker 一键部署，自带管理界面和 API。咱们 AI 问答的核心功能它全覆盖，我们只做门户和对接——这叫不重复造轮子。 |
| **百炼和 WorkBuddy 积分怎么用？** | 正式产品的 AI 走已购的百炼套餐（WeKnora 直连）。WorkBuddy 官方积分用于"双平台对比验证"的实验任务（R10），单独领任务做，产出一份对比报告。 |
| **谁说了算？出了分歧听谁的？** | 日常看契约文档（字段、API 格式，10/4 冻结）；契约要改找集成负责人走变更流程；方向性的事我拍板。 |
| **demo 前来得及吗？** | 来得及，方案是按 10/8 demo 反排的：10/4 冻结规则 → 10/5-10/8 冲刺 P0 六个页面 + AI 问答链路。国庆期间的任务都设计成"一人独立可完成"，不依赖集中碰头。 |
| **我领了任务干不完怎么办？** | 72 小时没提交自动释放，群里说一声"释放"也行，无损面子，别人接着干。小块任务本身就不大（单个 ≤2 天量）。 |
