# 零废弃知识库 · 本地跑通说明书

> 给：志广（P4 组长）
> 用途：把项目拉到本地，起起来，看现在的实际效果
> 预计耗时：**10 分钟**（主要花在装依赖）

---

## 一、你只需要跑起来，不用配任何东西

**先说结论**：现在跑起来**不需要连 WeKnora**，不需要填任何密钥。

因为后端内置了一套**"本地资料模式"**——它读仓库里那份 `kb-index.json`（35 份真实资料），
照样能出书架、能筛选、能搜索。**WeKnora 只是让 AI 问答能工作，书架不依赖它。**

---

## 二、准备工作（只做一次）

### 1. 装 Node.js

要求 **Node.js 20 或更高**。

检查有没有：
```bash
node -v
```
- 显示 `v20.x` 或更高 → ✅ 跳过
- 显示更低版本，或"命令未找到" → 去 [nodejs.org](https://nodejs.org) 下载 **LTS 版**装上

### 2. 装 Git

```bash
git --version
```
没有的话去 [git-scm.com](https://git-scm.com) 装。

---

## 三、拉代码（3 条命令）

打开终端（Windows 用 **Git Bash** 或 **PowerShell**，Mac 用**终端**）：

```bash
git clone https://github.com/a3230038469/zero-waste-p4.git
cd zero-waste-p4
```

---

## 四、装依赖（1 条命令）

```bash
npm install
```

> ⏱️ 这一步**最慢，要 2-5 分钟**，屏幕会滚一堆东西，正常。
> 装完看到类似 `added 500 packages` 就成了。

**如果卡住不动**（国内网络常见），换淘宝镜像再试：

```bash
npm config set registry https://registry.npmmirror.com
npm install
```

---

## 五、配一个最简环境文件

进 backend 目录，复制一份环境模板：

```bash
cd backend
cp .env.example .env
```

> **这一步不能省**——后端启动时要求有这个文件，否则会报错。

**然后打开 `.env`，只改两行就行**（用记事本/VSCode 都行）：

```ini
# 找到这两行，随便填一串够长的字符：
JWT_SECRET=local-demo-please-change-this-to-any-long-string
ADMIN_STATS_TOKEN=local-demo-admin-token

# 数据库路径改成这个（避免找不到文件）：
DATABASE_URL="file:./prisma/dev.db"
```

**其他的（WEKNORA_* 那几行）不用动**，现在用不上。

---

## 六、初始化数据库（1 条命令）

还在 `backend` 目录里：

```bash
npx prisma generate
npx prisma db push
```

> 这两条是给"用户注册登录"建表用的。看到 `Your database is now in sync` 就成了。

## 七、起后端（开一个终端窗口）

```bash
cd backend
npm run dev
```

**成功的样子**：
```
[backend] listening on http://localhost:4000
[weknora] 本地数据源已启用：35 份资料（.../backend/data/kb-index.json）
```

> 👀 **看到"35 份资料"这行，说明数据接上了。**

**验证一下**（另开一个终端窗口）：
```bash
curl http://localhost:4000/health
```
返回 `{"ok":true}` → ✅ 后端正常。

## 八、开一个"假数据开关"（关键一步！）

⚠️ **这一步最容易漏，漏了你就看不到真实数据。**

打开这个文件：

```
frontend/src/api/docs.ts
```

**第 15 行**，找到：

```js
const USE_MOCK = true
```

**改成**：

```js
const USE_MOCK = false
```

**保存。**

> 为什么有这个开关？梓柔写前端时后端还没好，她内置了 72 条假数据方便调样式。
> 现在后端好了，**必须切掉，否则页面显示的是假数据**。

## 十一、已知问题（不是坏了）

### 1️⃣ 下载/预览报错

```
资料文件不存在：kb/xxx.pdf
```

**原因**：PDF 原件有 60MB，**没放进仓库**（太大了）。
**影响**：详情页能看，但下载/预览不行。
**要修的话**：把 PDF 拷进 `backend/data/kb/` 目录即可（文件名要对得上）。

### 2️⃣ AI 问答不回答

**原因**：没连 WeKnora 引擎。
**影响**：书架、筛选、搜索**全部正常**，只是 AI 问答不行。
**要修的话**：需要连上 WeKnora 并配好 `.env` 里的 `WEKNORA_*`。

### 3️⃣ 首页资料数量

如果首页显示的数量和书架对不上，**告诉我**，是个待查的小问题。

## 十二、常见报错怎么处理

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `Cannot find module` | 依赖没装全 | 回到根目录重跑 `npm install` |
| `EADDRINUSE` | 4000/5173 端口被占 | 关掉之前开的窗口，或重启电脑 |
| `@prisma/client did not initialize` | 没跑 prisma 初始化 | 回 `backend` 跑第六节那两条命令 |
| 页面全是假数据（零萌公益） | **忘了切 USE_MOCK** | 回第八节，改成 `false` |
| `.env` 找不到 | 没复制 | `cd backend && cp .env.example .env` |
| 页面白屏 | 后端没起 | 确认后端窗口还在跑、`/health` 通 |

## 十四、一句话总结操作顺序

```bash
# 1. 拉代码
git clone https://github.com/a3230038469/zero-waste-p4.git
cd zero-waste-p4

# 2. 装依赖
npm install

# 3. 配环境
cd backend && cp .env.example .env
# 编辑 .env：填 JWT_SECRET、ADMIN_STATS_TOKEN，改 DATABASE_URL
npx prisma generate && npx prisma db push

# 4. 起后端（窗口1）
npm run dev

# 5. 改 frontend/src/api/docs.ts 第15行 USE_MOCK = false

# 6. 起前端（窗口2）
cd ../frontend && npm run dev

# 7. 浏览器打开 http://localhost:5173
```
