## 三、关键事实（云端必须知道，别再踩）

1. **云端沙箱连不上 GitHub**（平台限制）：所有"推送到 GitHub"类的活云端都干不了。队友交付 = 网页拖拽上传（文档包《成果上GitHub教程》已按此设计）。拉协作者、仓库配置类操作 → 把需求**传回本地管家**执行。
2. **main 分支保护当前未开**：GitHub 免费账号的私有仓库不支持（实测 403）。也就是说现在**任何人被拉进仓库都能直接改 main**。对策二选一：① owner 申请 GitHub 学生包（Student Developer Pack，免费解锁，中国学生可申请但有通过率风险：需先开两步验证、姓名与证件一致、中文学生证配英文翻译、申请时尽量不挂代理，被拒可人工申诉）；② 未解锁期间靠纪律 + 集成负责人盯提交记录，出问题靠 git 回退。
3. **仓库里 README/CONTRIBUTING 写的是"main 受保护"**，与现状不符——若学生包没办成，建议云端在发群话术里弱化这条，避免误导队友。
