# 演示前要问的问题清单

> 日期：2026-10-13｜用途：今晚给老师和赞助方沟通时照着问  
> 每一问都写了"为什么问 / 答案影响什么"，方便对方说"不知道"时你知道下一步怎么办

---

## 一、先问"有没有"（我们暂时不需要，有就直接省一大笔）

### 1️⃣ 有没有可以借的服务器？

**为什么要问**：我们的网站现在**跑在组员自己的笔记本上**，电脑一关、组员一出差，网站就没了。想长期对外，必须有一台常开的机器。

**问法**：「学校或基金会这边，有没有现成的、可以借给我们用的服务器？如果有，什么配置、有没有显卡？」

**答案影响**：

- 有 → 我们省掉服务器采购，直接部署（省一大笔）
- 没有 → 下面第五节的"成本对比"就得赞助方掏钱

### 2️⃣ 🔴 有没有**已经备案好**的域名？（这个最卡人）

**为什么要问**：服务器在国内的话，域名**必须先备案**才能用，备案流程要 **10～20 个工作日**，而且要提供单位/个人信息。**这是整个公网部署路上最大的时间坑。**

**问法：「有没有已经备案好的域名可以给我们用？或者域名备案这块，我们该找谁、走什么流程？」**

**答案影响**：

- 有备案域名 → 我们能直接上线公网
- 没有 → 要么等备案（十几二十天），要么先用服务器 IP + 高位端口凑合（能演示但不好看、不能对外宣传）

## 二、模型 API：确认这几件事

### 3️⃣ 阿里百炼的 token 包，具体能用哪些模型？

**为什么要问**：听说赞助方那边有阿里百炼的 token 包，如果直接连 API，我们就不用自己部署大模型，省掉显卡服务器的钱。

**要确认清单**：

| 要问的                                       | 为什么重要                                          |
| ----------------------------------------- | ---------------------------------------------- |
| **有没有"向量模型"（embedding / text-embedding）** | 🔴 **最关键**：知识库检索必须靠它把资料变成"数学坐标"才能搜。没有它，问答功能用不了 |
| 有没有对话/问答模型（qwen 系列之类）                     | 负责生成回答                                         |
| **token 额度有多少、够我们用吗**                     | 我们每问一次都消耗额度，得知道够不够                             |
| **token 包有没有有效期**                         | 过期了要续                                          |
| 是不是**多个项目共用**一个 token 包                   | 别人用了会不会把我们的额度花光                                |

### 4️⃣ 🔴 我们的资料，传到第三方 AI 接口，合规吗？

**为什么要问**：如果资料里有些内容不方便传到外部平台（基金会内部资料、含联系方式或个人信息），就**只能走本地部署**，那成本就完全不一样了。

**问法**：「这批零废弃资料会传到阿里百炼的接口上处理，赞助方这边对数据外传有没有什么要求或限制？」

**答案影响**：

- 允许 → 走 API，省服务器
- 不允许 → 必须本地部署 → 显卡服务器的钱跑不掉

### 5️⃣ 有没有"排序/筛选"更准的模型（rerank）？

**为什么要问**：有一类模型专门负责"把最相关的资料排到最前面"。有了它，问答更准。**没有也不影响继续做。**

## 三、MinerU（文档解析）—— 🔴 这是目前唯一可能需要花钱的技术项

### 6️⃣ 现状说明（给对方解释清楚，我们用它干什么）

我们的 600 多份资料里，很多是 PDF 和扫描件。**MinerU 是把这些文件"读成文字"的专业工具**，没有它，资料库里就只有一堆读不出来的空文件。

### 7️⃣ 两条路，请对方选（这是今晚最需要说清楚的一件事）

| 方案                  | 一次性花钱    | 每月花钱 | 限制                                            |
| ------------------- | -------- | ---- | --------------------------------------------- |
| **A. 用免费版 API**（推荐） | 0 元      | 0 元  | ⚠️ **API 密钥 90 天要换一次**；如果**不频繁更新新资料**，免费版完全够用 |
| **B. 自己部署**         | 服务器 + 显卡 | 每月租金 | 没有 90 天限制，但要自己养着、有运维                          |

**要说清的三个关键点**：

1. **90 天换密钥不是大问题**——就是换一串密码，我们自己做，提醒一下就行，**不影响任何功能**。
2. **免费版够用的前提**：**只在需要新增/重新解析资料时才用到它**。日常问答、检索、下载**完全不依赖它**。我们目前资料基本已解析完，**用得很少**。
3. 🔴 **选 B 就要买带显卡的服务器，成本会明显上升**（AI 要显卡才能跑，服务器本身也要一直开着）。**所以默认选 A，除非赞助方愿意专门出这笔显卡服务器的钱。**

**问法**：「资料解析这块，我们用免费版 API 就够了，唯一的麻烦是密钥 90 天要换一次。如果想免掉这个麻烦，就得自己部署、买带显卡的服务器——这笔钱赞助方这边是否支持？还是我们就用免费版？」

### 8️⃣ 如果用免费版，谁负责换密钥？

**问法**：「免费版密钥 90 天到期，我们会提前提醒。如果赞助方那边有统一的账号管理，能不能把到期时间告诉我们一声？」

## 四、我补充的几个要问的（容易漏但都重要）

### 9️⃣ 化学品那 123 份资料，要不要让 AI 自动补分类标签？

**现状**：零废弃那 480 份全都有主题标签，但**化学品那 123 份一份都没有**。演示时点"主题"筛选器会只显示"未标注"，不好看。

**建议**：让 AI 读每份资料的内容，自动提取主题（邻苯二甲酸酯、PFAS、农药残留、抗生素、甲醛……），大概一两个小时能跑完。

**问法**：「化学品那批资料的主题分类，我们打算让 AI 自动生成，可以吗？还是贵方有既定的分类标准要按着来？」

### 🔟 署名和致谢怎么写？

**为什么要问**：交付物上要写清楚是谁做的、资料来自哪里。

**问法**：「最终交付的网站和说明文档，署名要写哪些单位？需要致谢志愿者名单吗？用什么形式（文字 / 徽标）？」

### 1️⃣1️⃣ 最终版什么时候要？

**为什么要问**：公网上线要走备案，时间不可控。**要倒推排期。**

**问法**：「最终版希望什么时候交付？有没有必须赶上的节点（比如结营、评审）？」

### 1️⃣2️⃣ 验收标准按什么算？

**为什么要问**：我们想确认"做到什么程度算完成"，避免来回返工。

**问法**：「验收是看需求文档里那 19 个问题都能正常回答，还是有别的标准？」

## 五、成本对比（给赞助方看的，一句话总结）

**我们现在的省钱路线是**：

> 资料存在服务器上 + 智能引擎用开源免费版 + AI 问答接赞助方的百炼 API → **软件这块几乎零成本**

**唯一可能要花钱的地方**：如果希望解析工具 MinerU 免掉"90 天换密钥"，就得买带显卡的服务器。
