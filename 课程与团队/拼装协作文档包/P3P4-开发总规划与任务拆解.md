## 1. 技术栈定稿

> 技术栈 = 全组统一使用的工具组合。选它因为：主流 + AI 生成质量高 + 一种语言（TypeScript）贯穿前后端，队友学习成本低。

| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | **Vue 3 + Vite + TypeScript** | 与 WeKnora 自身前端同栈，可参考其源码；AI 熟悉度极高 |
| UI 组件库 | **Element Plus** | 中文文档、表格/表单/筛选组件齐全，书架页现成轮子 |
| 前端路由/状态 | Vue Router + Pinia | 标准搭配 |
| 后端 | **Node.js 20 + Express（TypeScript）** | 轻量、AI 生成可靠；与前端同语言 |
| 数据库 | **SQLite + Prisma ORM** | 零运维，数据量（注册用户+统计日志）完全够用；Prisma 未来换 PostgreSQL 只改配置 |
| 用户认证 | 自建 JWT（jsonwebtoken） | 注册五字段自管，与 WeKnora 账号体系隔离 |
| 引擎对接 | WeKnora REST API（`/api/v1`，`X-API-Key`） | 见第 3 节，唯一对接层 |
| 部署 | Docker Compose + Nginx | 与 WeKnora 部署方式一致，交付基金会照文档跑 |
| 代码托管 | GitHub 私有仓库（P3/P4 协作） | 分支规范：`main` 保护，功能分支 `feat/Txx-名称` |

**禁止事项**：不引入第二语言/框架（如 React、Python 后端）；不直接从前端调 WeKnora API（必须经自建后端）。

## 5. 自有后端 API 契约（前端只认这套，不许直连 WeKnora）

```
POST /api/auth/register        # 五字段注册
POST /api/auth/login           # 返回 JWT
GET  /api/auth/me              # 当前用户

GET  /api/docs?type=&org=&year=&tag=&q=&page=&sort=   # 书架列表（聚合 WeKnora+本地名检索）
GET  /api/docs/:id                                     # 详情
GET  /api/docs/:id/preview                             # 预览内容（后端代理）
GET  /api/docs/:id/download                            # 校验登录 → 302 到预签名URL

POST /api/embed/token          # 校验登录态(可选) → 调 WeKnora exchange → 返回 session token
POST /api/webhook/embed        # 接收 WeKnora 问答回调（验签）

GET  /api/admin/stats/questions  # 提问趋势/无答案率/热词
GET  /api/admin/stats/downloads  # 下载排行
GET  /api/admin/stats/users      # 注册身份分布
```

**数据表**（Prisma）：
- `User`：姓名、机构、职业、关注议题、电话、密码哈希
- `QuestionLog`：会话ID、提问原文、是否命中、时间（Webhook 写入）
- `DownloadLog`：用户ID、文档ID、时间
- `Submission`（P2）：提交内容、状态、审核意见

**元数据维护分工（v1.1 增补，2026-10-05 定）**：
- 钉钉表格五列全部进 WeKnora：知识名=文件名、PDF=文件本体、机构/年份/类型/领域=custom_metadata（实测接口读写通，详见《实验报告-自定义元数据与书架筛选.md》）
- **字段真源=人工**：AI 自动打标对正式库默认关闭；400+ 存量走批量导入脚本从 Excel 搬（不手打）；日常新增走自建管理页的"新增资料"表单（四字段固定+点选，后端调 WeKnora API 写入）——WeKnora 自带界面的元数据编辑是白板式、无批量，只当"仓库"不当录入工具
- 公众提交必须人工审核后才入库；Excel 空值显示"未标注"，不编造
- 书架筛选/排序：自建后端同步知识列表（含 custom_metadata）进 SQLite 索引（WeKnora 列表不支持按元数据筛排，实测）

### 阶段四：节后（10/9 起）
