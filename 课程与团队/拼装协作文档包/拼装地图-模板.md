# 拼装地图（草稿模板）

> **用途**：全组唯一事实源，一眼看清"谁负责哪块、做到哪了、拼到哪去"  
> **用法**：每行 = 一个可独立交付、可独立验收的"小块"，负责人对该块"能接上别的块"负责  
> **维护**：小块负责人自行更新状态，集成负责人每周核对  
> **版本**：v0.1 模板（负责人待指派）

---

## 状态口径（统一使用，不许各说各话）

```
☐ 未开始   ◐ 开发中   ● 已提交   ▶ 已合入主干   ✅ 验收通过
```

## 三、依赖关系图（谁卡着谁）

> 用文字版拓扑，方便随时核对。箭头 = "必须先完成 A 才能开始 B"

```
C2/C3/C4 契约冻结 ──→ 所有开发块
                        │
R01 登录 ──→ R02 知识库浏览 ──→ R03 检索 ──→ R04 统计
                        │            │
                        ↓            ↓
                    R06 预览下载   R05 AI问答 ──→ R05-E 多轮对话
                                     │
                        R05-B 自建RAG ──→ R05-C 混检重排
                        R05-A 平台原生（独立，可与 R05-B 并行）
```

**关键路径**：契约冻结 → R01 → R02 → R03 → R05 → R05-E。  
**并行机会**：R05-A（平台原生）与 R05-B（自建 RAG）可并行互不阻塞。
