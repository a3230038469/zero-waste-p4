## 三、你要动手做的事（操作清单）

| # | 要做的事 | 细节 |
|---|---|---|
| 1 | **改昵称** | 把 WorkBuddy 上的微信昵称改成「**真实姓名 + 小组名**」；助教要加斜杠标双组名 |
| 2 | **装 WorkBuddy** | 电脑版和小程序都能登，**不需要谷歌账号** |
| 3 | **每日领积分** | 点头像每天领 **100 积分**（当前额度只够轻量任务） |
| 4 | 建项目 | 桌面新建项目，命名格式「**方向 + 项目组**」；直接复制群内手册里的项目指令 |
| 5 | 配飞书 CLI | 通过对话让 WorkBuddy 自己配，点授权链接完成；**只需配一次**，按账号读全部文档 |
| 6 | 连通性测试 | 让 WorkBuddy 读一份飞书文档，能读出来就算通 |
| 7 | 换模型 | 推荐 **deepseek pro**（响应明显更快）；模型倍率越高越聪明但消耗越快 |

> ⚠️ **本项目必须由助教创建**（不是学员自己建）——因为 token 消耗走助教账号，避免烧掉学员个人额度。
> 项目空间当前有 **5 人邀请上限**（免费版权限），等官方开通高级权限后解除；小组资料库也由助教建（公共资料 / 过程资料 / 正式作业 三层）。

## 四、⭐ 本期核心新增：Skill 制作

**这是第四期相比往期新增的核心服务。** 官方态度：**首周就可以开始做**，边做边更新，不用等最后。

### 激励
- 优秀作者**最高 4000 积分**（讲师折算约 100 元）+ 单项荣誉
- 作品将**上架腾讯公益平台**的 skill 栏目展示

### 六步流程（照着做就行）
1. 复制官方 prompt，跟 WorkBuddy 对话，**系统一步步引导**
2. **第一阶段**：系统多轮提问，收集你的背景 / 项目经历 / 痛点 → 输出一份「**自我定位表格**」
3. **第二阶段**：把定位表格喂回去 → 确定 skill 方向
4. **经验提取**：把"你脑子里知道但没写下来的经验"（know how）通过多轮对话显性化
5. **开发 + 测试**：上传真实业务数据 → 系统自动找问题、给迭代建议 → 多轮打磨（可到 v6、v7）→ 调用验收 skill 出验收报告
6. **入库上架**

### 可以做什么 skill（讲师举的例子）
- 活动推文初稿生成（现场演示案例）
- **会议纪要**、进度同步、答辩经验
- **PRD 撰写**、竞品分析、品牌传播方案
- 助教方向：**作业批改**（把人工审核经验打包给 AI）

> 讲师原话精神：**"万物皆可 skill"**——不用担心做出来适配性差，系统 prompt 会自动把关；选题不必局限官方给的方向，鼓励自由发挥。

## 六、现场卡点（记下来，别人踩过的坑你就不用踩）

- 会前文档权限没开，开场延迟了 1 分钟
- 项目空间 5 人上限导致部分人加不进去 → 官方说等高级权限

- 配置过程中出现无 token、页面卡顿、授权失败 → 讲师建议：**重新发授权链接 / 重开任务窗口 / 直接跟 WorkBuddy 对话让它自己排错**，别硬磕
