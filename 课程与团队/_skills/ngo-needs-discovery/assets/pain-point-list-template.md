# 痛点清单模板（存为 04-痛点清单.md）

```markdown
# <机构名> · 痛点清单
> 来源：<第一轮访谈 / 机构材料 / 公开资料>　｜　整理日期：YYYY-MM-DD

## 一句话问题定义

> 【我们推，待确认】<谁> 在 <什么场景> 下，因为 <根因>，导致 <损失>。

## 痛点明细

### P1 · <痛点标题>

| 项 | 内容 |
|---|---|
| 表层现象 | <对方原话在抱怨什么> |
| 根因（追问五层后） | <能动手改的那一层> |
| 所在环节 | <七条引擎中的哪一条> |
| 原话证据 | "<原话>" —— <谁>，<时间点> |
| 频次 | 每天 / 每周 / 每月 |
| 影响 | 一个人一件事 / 一条链路 / 机构生存 |
| 能否验证 | 一周内 / 一个月内 / 说不清 |
| 优先级得分 | 频次 × 影响 × 可验证 = <分数> |
| 来源标记 | 【他们说】/【我们推，待确认】 |

### P2 · <痛点标题>
（同上结构）

## 排序总表

| 排序 | 痛点 | 得分 | 证据强度 |
|---|---|---|---|
| 1 | | | 有原话 / 仅推断 |

## 待确认清单

| # | 要确认什么 | 找谁确认 | 什么时候 |
|---|---|---|---|
| 1 | | | |

## 被排除的条目及原因

| 条目 | 为什么排到后面 / 排除 |
|---|---|
| | |
```

## 填写示例（真实片段）

```
### P1 · 知识库内容出不去

| 项 | 内容 |
|---|---|
| 表层现象 | "知识库前端页面和操作路径待优化" |
| 根因（追问五层后） | 内容与问答被绑定在需要登录的平台内，外部访客拿不到 —— 卡在"发布通道"，不是内容质量 |
| 所在环节 | 受益人连接 |
| 原话证据 | "因为平台限制，下载功能和 AI 助理功能需加入钉钉平台使用，暂无法对外" —— 机构方，<时间点> |
| 频次 | 每天（内容持续产出、持续发不出去） |
| 影响 | 一条链路（受益人连接） |
| 能否验证 | 一周内可验证 |
| 优先级得分 | 3 × 2 × 3 = 18 |
| 来源标记 | 【他们说】 |
```

**注意**：示例中的得分依据要能复核；同一批痛点必须用同一套打分口径。
