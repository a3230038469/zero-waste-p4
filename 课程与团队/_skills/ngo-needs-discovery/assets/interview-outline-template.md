# 访谈提纲模板 + 访谈记录模板

## 一、访谈提纲（存为 02-访谈提纲.md）

```markdown
# <机构名> · 访谈提纲
> 访谈对象：<姓名/职务>　｜　时间：<日期 时长>　｜　形式：<线上/线下>

## 开场（1 分钟）
1. 说明来意：我们是 <团队>，想在 <周期> 里帮你们解决一个具体问题。
2. 说明记录：这次会做文字记录，只用于我们内部梳理，涉及敏感内容可以随时说"这段别记"。
3. 请对方随时打断纠正我们的理解。

## 主线问题

### A. 业务现状（对应框架 1—3 层）
- A1 <问题>
  - 追问：<更具体的问法>
  - 追问：<要事实不要评价的问法>
- A2 <问题>
  - 追问：
  - 追问：

### B. 谁在做、花多久（对应第 4 层）
- B1 <问题>
  - 追问：

### C. 卡在哪（对应第 5 层）
- C1 <问题>
  - 追问：为什么？为什么？为什么？
  - 条件替换：<换一个前提再问一次>

### D. 值不值得做（对应第 6 层）
- D1 如果这件事不再发生，你们能腾出什么？

## 结束前三句（必问）
1. 这些话里，您最想先解决哪个？
2. 除了您，还有谁能拍这个板？
3. 我们理解 A 是 B，对吗？

## 备用问题（时间富余时问）
- 
```

**填写要求**：每个主线问题下至少 2 个追问；追问必须是"要事实"的问法，不是"要评价"的。

## 二、访谈记录（存为 03-访谈记录.md）

```markdown
# <机构名> · 访谈记录
> 访谈对象：<姓名/职务>　｜　时间：<日期 起止>　｜　记录人：<谁>

## 原话摘录（不改写）

| # | 时间点 | 谁 | 原话 | 我的备注 |
|---|---|---|---|---|
| 1 | 00:03 | <姓名> | "<原话>" | <当场想到的追问方向> |
| 2 | | | | |

## 现场观察（非语言信息）
- <对方在哪一段明显停顿、皱眉、加快语速；提到谁时语气变化>

## 当场确认到的事实
- 【他们说】<机构亲口确认的事实>

## 未问清 / 待确认
- 【待确认】<问题> —— 下一步找谁确认

## 下一轮要追问的
1.
```

**记录纪律**：左侧写原话，右侧写我们的推断，两栏不混。原话栏不许出现归纳句。
