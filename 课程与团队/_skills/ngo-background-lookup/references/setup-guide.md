# 运行环境与配置说明

本技能不需要账号、密钥或任何登录，只有一个运行条件：**能访问外网**。

## 依赖项

| 依赖 id | 依赖 | 类型 | 必需 | 用途 |
|---|---|---|---|---|
| `web-search` | 联网检索 | 网络 | 是 | 检索机构官网与公开披露信息、媒体报道与行业奖项，并校验来源链接可达性 |

**官方入口**

- 宿主产品主页：https://www.workbuddy.cn/
- 宿主官方文档：https://www.workbuddy.cn/docs/workbuddy/Overview

联网检索由宿主平台提供，不需要单独安装客户端，也没有需要申请的凭据。技能内附的 `scripts/check_environment.py` 只用 Python 3.10+ 标准库运行，仅作只读检查，不修改任何配置。

## 配置步骤

1. 确认本机能访问外网（浏览器能打开任意公开网页即可）。
2. 无需注册账号，无需申请密钥，无需登录。
3. 如需机器自检，运行 `scripts/check_environment.py`；它只读取状态，不写入、不登录、不授权。

## 验证方式

对一个已知存在的公开网址发起一次访问或检索，能返回内容即视为可用。脚本侧的检查项：`net-reach`（对公开站点发起一次 HEAD 请求，接受 200／301／302）、`python-available`（确认 Python 版本不低于 3.10，可选）。

## 安全规则

- 只检索公开信息；不使用、不上传用户提供的机构内部材料。
- 不向任何外部服务提交凭据（本技能也不需要凭据）。
- 检索结果必须保留来源链接，便于用户复核。
- 脚本不输出任何环境变量或凭据值。

## 不可用时怎么办

| 情况 | 处理 |
|---|---|
| 网络不可用 | 只处理用户提供的材料；输出时标注"未经联网核实"，并列出要靠访谈补充的缺口 |
| 检索无结果 | 输出一页纸骨架，只填"未找到"与待核实问题，不推测补位 |
| 检索结果互相矛盾 | 并列两条并标注来源与日期，标记为待确认 |
| 单个来源链接不可达 | 保留来源名称与获取日期，注明链接当时不可达 |

## 恢复与撤销

网络恢复后重新运行本技能即可，无需清理任何配置——本技能不产生本地凭据，也没有需要撤销的授权。
