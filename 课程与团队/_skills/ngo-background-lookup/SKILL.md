# 机构背景速查

给一个公益机构名字，出一页纸画像：它靠什么运转、卡在哪、哪些信息还没找到。

## 何时使用

用户想快速了解一家公益机构时使用：刚拿到对接名单、访谈前要做功课、报告里需要机构背景。

## 输入与输出

**输入**：机构名称（有官网／公众号／统一社会信用代码更准）
**输出**：一份 `机构一页纸`，含业务实质、四要素体检、可能卡住的引擎、来源清单、未找到的信息、待核实问题

## 步骤

1. 先确认机构唯一性：全称、注册地、成立时间。**同名机构必须区分**，区分不了就先问用户要全称或链接。
2. 检索公开资料，按以下顺序，每条结论都要能指回来源：
   - 机构官网、官方公众号
   - 年报／年度工作报告／财务披露（基金会中心网、慈善中国等公开披露平台）
   - 媒体报道、行业奖项、项目公告
   - 联合发起方、合作方、资助方名单
3. 填四要素体检：
   - **身份与合规**：注册形式、业务范围、有没有公开财务
   - **资源获取**：钱从哪来（月捐／政府购买服务／企业捐赠／基金会资助）、人从哪来（全职／志愿者）
   - **服务转化**：钱和人怎么变成具体服务
   - **影响力反馈**：成果怎么回到捐赠方与公众
4. 判断可能卡在哪条业务引擎：筹款／立项书撰写／志愿者招募与管理／活动运营／受益人连接／多方协作／内部合规。判断要写理由，并标 `【我们推】`。
5. 写"未找到的信息"和"待向机构核实的问题"两节。**查不到就写查不到**，不留空格也不猜。
6. 输出一页纸（模板见 @assets/org-onepager-template.md），所有结论标来源。

## 通过条件

- 一页纸里每条事实都能指回一个来源（链接或资料名）
- 所有推断都带 `【我们推】`，没有和事实混排
- "未找到的信息"非空（正常情况下总会有查不到的部分）
- "待向机构核实的问题"至少 3 条，且是能直接问出口的话

## 失败分支

| 情况 | 怎么办 |
|---|---|
| 检索不到任何有效资料 | 输出一页纸骨架，只填"未找到"+ 待核实问题，明确告知：全靠访谈补 |
| 只能找到二手转载、内容互相矛盾 | 两条都列，标明各自来源，标为 `【信息冲突，待确认】`，不选一个当结论 |
| 同名机构无法区分 | 停下来问用户要全称、所在地或官网链接，不硬猜 |
| 网络不可用 | 只处理用户提供的材料；输出时标注"未经联网核实" |

## 边界

- 只处理公开信息。用户提供的机构内部材料、聊天记录、未公开文档，不用于对外检索，也不上传到任何外部服务。
- 不评估机构好坏、不给公益项目打分、不做道德评价。
- 不代替需求访谈。一页纸是访谈的起点，不是结论。

## 交付前自查

- [ ] 机构全称、注册地、成立时间已确认，无同名混淆
- [ ] 四要素每一项都有内容或明确写"未找到"
- [ ] 引擎判断写了理由并标 `【我们推】`
- [ ] 来源清单里的每条链接可达
- [ ] 待核实问题至少 3 条，且措辞能直接问出口
- [ ] 没有任何凭据、账号信息出现在输出里

## 停止条件

- 机构身份无法唯一确定，且用户无法提供全称或链接
- 用户要求把未核实的推测写成事实
- 用户要求检索涉案、涉隐私或非公开的个人信息
