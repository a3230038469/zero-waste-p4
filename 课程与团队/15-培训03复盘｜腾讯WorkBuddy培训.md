## 二、纪要要点（六块）

### 1. 产品定位与核心能力

| 要点 | 内容 |
|---|---|
| **AI 已经进入第三阶段** | 从"聊天"到"能直接操作电脑和本地数据、把事办成"；主张快速试错，有用的功能立刻固化 |
| **Agentic 全期产品** | 通过长期交互持续学你的习惯、标准、模板，越用越准 |
| **安全机制** | 本地部署、数据隔离、操作日志可回溯、沙箱运行；每个任务限定一个"文件夹工位"，越权要你授权 |
| **模型可选** | 默认混元等；可接 DeepSeek、智谱等外部付费模型；**高配电脑能装本地小模型**——数据更安全、还省积分 |

### 2. 三种工作模式（按信任度选）

| 模式 | 怎么干 | 什么时候用 |
|---|---|---|
| **Craft** | 直接开干 | 任务你很熟、也信它的产出 |
| **Ask** | 聊天式，会记住你的要求标准 | 初期探索、不确定怎么做的时候 |
| **Plan** | 先想后做，先出大纲要点，你确认后再生成 | 复杂内容（比如长篇 PPT） |

**连接器生态**：腾讯文档、腾讯会议、邮箱等官方合作软件可直接连；没有官方连接器的，走 MCP 配置或 RPA 模拟操作。

### 3. 实操技巧

- **本地 + 云端协同**：读本地文件夹的素材出文件，也能直接生成在线文档放腾讯文档，方便团队一起改
- **局部圈选编辑**：在生成的 PPT / Word 里圈出某一块，直接让它只改那块的字体、颜色、背景，**避免全局乱改**
- **数据要复核**：数据准确性让它多次复核对比；排版类错误让它用视觉工具截图 OCR 检查
- **技能封装**：把常用的文档格式、PPT 模板、复杂流水线固化成"技能"，以后一句话按固定风格一键出

### 4. 团队协作与定时任务

- **多人双写**：用资料库建共享空间 / 项目空间，邀请成员进来，同一份文件实时协作
- **定时任务**：每日 / 每周频率、自动收集行业新闻并整理成 Markdown 放进指定文件夹
- **专家与专家团**：流程复杂或不清楚时，召唤领域专家 / 专家团帮你拆任务（例：技术公益专家团帮你封装公益技能）

### 5. 全栈应用部署与云托管

- **零代码搭应用**：一句话把模拟表格变成"带登录功能的救灾工作台"，交互逻辑和数据库自动生成
- **一键云托管**：开启云托管后自动调腾讯云 CVM、COS 完成部署上线，还有身份认证、访问统计、下线调试
- **记忆与进化**：账号记忆记录了你的工作描述与习惯，可手动调整，也能导入其他 Agent 的记忆

### 6. 风险提示与最佳实践 ⚠️

| 提醒 | 原话要点 |
|---|---|
| **自媒体别全自动** | 连小红书这类平台有**封号风险**——用 AI 生成草稿或排到草稿箱，**最终由号主手动审核发布** |
| **视频很烧积分** | 视频类操作消耗极高，先把剧本、分镜、运镜理清楚，再让它生成关键帧或用视频技能 |
| **⭐ 需求必须前置** | **给公益机构搭系统前，务必用问答模式对齐研发 PRD 文档，挖出隐性需求**，确保成果真正贴合机构业务 |

## 三、复盘：这场培训对我们组意味着什么

### ⭐ 三条直接印证了我们正在走的路

1. **"需求梳理前置"就是我们的四段流程**。讲师说"搭系统前务必对齐 PRD、挖隐性需求"——这正是 P4 组这周要干的事（备料 → 访谈 → 分析 → 交稿）。**别人听完是知识点，我们已经在干了。**
2. **"用问答模式挖隐性需求"= 我们的访谈 + 5 个为什么**。我们比这个说法更具体：带提纲、连问五层、条件替换验证。
3. **"技能封装"正是我们刚做的事**。今天刚把需求挖掘那套流程封成三个技能 + 一个专家（谭真需）——**讲师讲的方向，我们今天已经落地了，可以直接拿去参赛。**

### 可以立刻用上的三件

| 学到的 | 怎么用在 P4 组 |
|---|---|
| **Plan 模式（先想后做）** | 写需求报告、做汇报 PPT 这类复杂产出，先让它出大纲，我们确认了再展开——省掉大改 |
| **局部圈选编辑** | 六尺巷那份需求文档如果我们要改局部，圈出来只改那块，别让它全文重写 |
| **数据复核 + OCR 检查** | 需求报告里的数字（服务人次、资金占比）要让它复核并标来源；排版错让视觉工具截图核对 |

### 两个要留意的坑

- **截图 OCR 复核这条，跟我们技能里的"数字必须标来源"是配套的**——数字不能只靠它自查，最终要机构确认。
- **"共享空间多人双写"听着很美，但我们组是跨组织成员**（你是 ABC 租户外的），权限能不能开、5 人上限解没解，**得先问助教**，别默认能用。

### 与本次项目无关但值得他知道的

- **视频很烧积分** → 他手上另有"邯郸 AI 短视频大赛"用即梦，这条主要是 WorkBuddy 侧的提醒
- **自媒体别全自动直发** → 之前那个小红书贴纸号项目已停，暂时用不上
