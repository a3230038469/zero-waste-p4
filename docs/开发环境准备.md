# 开发环境准备（每人先做一次）

## 1. 装 Node.js
- 版本：**>= 20**
- 官网 `nodejs.org` 下载 LTS 版，装完命令行执行 `node -v` 能看到版本号即可

## 2. 装 Git
- 官网 `git-scm.com` 下载，装完执行 `git -v`

## 3. 拿到代码
```bash
git clone https://github.com/a3230038469/zero-waste-p4.git
cd zero-waste-p4
npm install
```

## 4. 跑起来自检
```bash
npm run dev:backend     # 终端 A
npm run dev:frontend    # 终端 B
```
然后：
- 浏览器打开 `http://localhost:5173` → 看到「零废弃知识库」页面
- 另一个终端执行 `curl http://localhost:4000/health` → 返回 `{"ok":true}`

**两条都通过，环境就 OK 了。**

## 5. 配自己的分支
```bash
git checkout -b feat/你的名字-模块
```
例：`feat/dingzi-frontend`、`feat/shaoru-backend`

**不要直接改 main。**

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| `npm install` 很慢 | 换国内镜像：`npm config set registry https://registry.npmmirror.com` |
| 5173 打不开 | 看终端有没有报错；端口被占就换一个 |
| health 请求失败 | 确认后端那个终端在跑，没报错 |
| 提交时报 lint 错 | 按提示改；改不掉就把报错原文发群里 |
