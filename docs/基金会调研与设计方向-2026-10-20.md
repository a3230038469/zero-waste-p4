## 2. 设计判断：什么叫"UI 味"，我们要避开什么

"UI 味"指的是：圆角卡片 + 阴影 + 胶囊标签 + 渐变按钮 + 图标装饰 + 光标特效 + 一个蓝/绿主色 + 无衬线字体。它是 SaaS 的通用皮。官网的红色模板也是同一类，只是颜色不同。

**我们要的是出版物的气质**：像一本印制精良的机构年报、一册书院的目录、一个博物馆的图录。它靠这些东西成立：
- **版心与留白**，而不是容器与阴影
- **字与号**：标题、页码、卷次、脚注，而不是图标
- **线**：细线分隔、目录的点线，而不是卡片
- **排版本身就是视觉**：大字、竖排、对齐、行距
- **印章**：朱红只用于一个位置

## 3. 设计母题（从 logo 长出来，但不复刻 logo）

logo 的结构是：两侧竖线由长到短向中间收拢，中间留一道空隙，下方是宋体名称。
我们从它抽出三个可以用在页面上的规则：

1. **"三尺"间距**：所有列表、段落的留白统一用一个基准单位，"让出的空白"成为节奏。不用装饰线。
2. **"巷"的阅读方向**：长页面是竖向的，像沿巷子走；章节之间用一组由长到短的细竖线做分隔（只在章节边界出现一次，不做背景纹理）。
3. **"让路"**：资料库的筛选不做成下拉框堆叠，而是**目录式展开**——左侧是目录，选中的条目展开，其它条目向两侧"让开"。

## 4. 色彩与字（严格受限）

| 角色 | 色值 | 用途 |
|---|---|---|
| 纸 | `#F4F1EA` | 页面底（宣纸，不是白，不是绿） |
| 墨 | `#1C1C1A` | 正文、标题、logo |
| 墨淡 | `#5F625C` | 次要文字、页码、来源 |
| 石 | `#8A8F88` | 脚注、时间戳 |
| 线 | `#D8D3C6` | 分隔线（只用线，不用面） |
| 青绿（可选） | `#2E5B4B` | 链接、选中态（极少） |
| 朱 | `#B0392F` | **仅**印章：「支持我们」一处、重要公告一处 |

- **不用渐变，不用阴影，不用圆角超过 2px**。
- 标题：宋体（系统栈 `Noto Serif SC / Source Han Serif SC / Songti SC / SimSun`），大字号，行距紧。
- 正文：16px 起，行高 1.85，中文不用斜体。
- 数字：宋体 + `tabular-nums`，数字后置单位，下方一行口径（如"截至 2026-10-20，资料库收录"）。
- 英文：只用 logo 里的拉字距英文做页眉，不做装饰性大写。

## 5. 结构：不做"首页 + 卡片墙"，做"目录 + 卷"

### 5.1 首页（一页长文，不是轮播）
1. **扉页**：左侧一句大字 + 一行小字；右侧不放图。
   - 大字建议（待定，可替换）："千里来书只为墙，让他三尺又何妨" 放在最上面作为引语（小字），主标题写："把零废弃与化学品的知识，整理成一条可以走进去的巷子。"
2. **目录**：五个工作领域，用目录式排列（序号 · 领域名 · 一句话 · 资料数 · 页码），不做卡片。
   - 有资料的领域：显示真实数量（零废弃 480、化学品与健康 123）
   - 无资料的：写"建设中"，并给官网栏目外链
3. **数字**：一行，三个数，各配口径。
4. **知识库入口**：一个检索框 + 下面一排"热门检索词"（纯文字，不做 chip）。
5. **引用与来源**：全文末尾的 colophon：机构信息、备案号、数据更新日期、授权说明。

### 5.2 资料库（知识库的主页面）
- 版式：左侧目录（类型 / 领域 / 年份，带计数），右侧为**条目列表**，不做卡片网格。
- 每条：编号 · 标题 · 类型 · 发布机构 · 年份 · 来源与授权（一行小字）。
- 筛选写进 URL，可分享。
- 空态一句人话："没有符合条件的资料，可以放宽年份或换一个领域。"

### 5.3 AI 问答
- 不做聊天泡泡。做成"问答稿"：问题居上，回答居下，每段回答末尾是脚注式来源编号 `[1]`，点击跳到右侧"引文"栏。
- 这是 LOC 式闭环：首页热门词直接进入问答。

### 5.4 关于 / 信息公开
- 以"页"为单位：机构简介、宗旨、三大业务方向、章程、年报、审计（占位，等机构提供）。
- 长文排版，不做 hero。

## 6. 导航（6 项，纯文字，无按钮感）

`首页　我们的工作　知识库　问答　信息公开　关于`

- 右上只放"登录"两字。"我要投稿"放在知识库页底部，不放导航。
- 手机端：纵向列表，不做抽屉动效。

## 7. 需要小志确认的问题

1. **方向**：这套"出版物气质"是否接受？它比前一轮的 A 案更克制，几乎没有"界面感"。
2. **标题文案**：首屏用"千里来书只为墙…"作引语是否合适？正式主标题由机构确认。
3. **官网数据冲突**：灯塔慈善查询显示"门户网站 无 / 官方微信公众号 无"，但前期访谈及官网实测显示有官网（`jzs.508sys.com` 模板站）。需确认官网真实域名与运营主体，否则页脚的"官网"外链会写错。
4. **logo 授权**：使用官方黑白 logo 需机构书面确认。
5. **资料数口径**：首页数字用当前 603 份，还是公众号宣称的 350+（2026-05）？建议用当前实测并标注日期。
