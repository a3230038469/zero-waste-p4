## 改法（带行号）

### 1. `frontend/src/api/contributions.ts`（第 198–224 行）

**问题**：原 `openContributionFile` 先 `await` 取 blob 再 `window.open(url)`，异步后开窗被浏览器拦截，导致“点原件没反应”。

**修改**：
- 第 203 行：同步先开空白窗口 `const w = window.open('', '_blank')` 拿到引用
- 第 204–208 行：`w` 为 null 时抛出中文错误“浏览器拦截了新窗口，请允许本站弹窗后重试”，不静默失败
- 第 210–223 行：`try/finally` 结构，`objectUrl` 变量记录创建的 URL；`finally` 里统一 60 秒后回收（成功/失败都回收）
- 移除了原来的 `catch (err) { throw err }` 无用捕获（eslint `no-useless-catch`）

### 2. `frontend/src/views/AdminContributionsView.vue`

**脚本部分**：
- 第 46–49 行：新增分页状态 `page`（默认 1）、`pageSize`（默认 20）、`total`（总数）
- 第 70–90 行 `load()`：传入 `page` 与 `pageSize`，接收 `data.total` 赋值 `total.value`
- 第 92–96 行 `switchFilter`：切筛选时 `page.value = 1` 重置首页
- 第 99–102 行 `search`：搜索时 `page.value = 1` 重置首页
- 第 104–108 行 `resetKeyword`：清空关键词时 `page.value = 1` 重置首页

**模板部分**：
- 第 344–353 行：表格后新增 `<div v-if="total > pageSize" class="pagination-wrap">` 包裹 `el-pagination`
  - `v-model:current-page="page"` 双向绑定当前页
  - `:page-size="pageSize"` `:total="total"` `:page-sizes="[20, 50, 100]"`
  - `layout="total, sizes, prev, pager, next, jumper"` 显示总数、每页条数切换、翻页、跳页
  - `@size-change="page = 1"` 切换每页条数时回首页

**样式部分**：
- 第 483–487 行：新增 `.pagination-wrap` 右对齐、上边距 16px
