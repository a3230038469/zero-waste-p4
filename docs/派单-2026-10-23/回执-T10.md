### 2. 修改说明

#### 2.1 `backend/src/errors/types.ts` - `normalizeErrorBody` 增加兼容性

**问题**：原 `normalizeErrorBody` 仅处理 `{success:false, error:{...}}` 形状，对以下两种形状缺乏兼容：
- 扁平 `{code,message}`（无 success 字段）
- `{success:false,type:'error',content}`（需保留 type/content 同时补 error 字段）

**修改**：
- **形状1（扁平 `{code,message}`）**：检测 body 顶层存在 `code` 和 `message` 但 `success !== false` 时，转成 `{success:false, error:{code,message,requestId}}`
- **形状2 (`{success:false,type:'error',content}`）**：保留 `type`/`content` 字段，并在 `error` 内补齐 `code:'ASK_ERROR'` 与 `message:content`，并添加 `requestId`；原有 `error.code` 优先保留（非 ASK_ERROR 时保持原值）
- **形状3（原有 `{success:false,error:{...}}`）**：行为完全不变，直接通过

#### 2.2 `backend/src/routes/ask.ts` - 开流前错误补充 `error:{code,message}`

**问题**：以下两处 400 响应缺少 `error` 字段，只返回 `type:'error'` 与 `content`：

- 第 366-367 行：`parseAskBody` 失败时的响应
- 第 370-373 行：query 长度超限时的响应

**修改**：在已有的 `{success:false, type:'error', content: '...'}` 基础上，补充 `error: { code: 'VALIDATION_FAILED', message: '...' }` 字段，实现“老字段不删、新字段齐全”。

#### 2.3 `backend/src/routes/overview.ts` - 500 错误通用中文文案

**问题**：`sendError` 函数返回 `err.message`，在 local 模式可能暴露绝对路径等内部信息。

**修改**：
- 将 500 分支的 `message` 改为 `'资料统计暂时不可用，请稍后再试'`
- 新增 `console.error` 日志，记录原始错误与 requestId（通过 `req.requestId` 获取），保持排障能力
- 保持HTTP状态码仍为 500，不吞掉状态码

#### 2.4 `backend/src/routes/chat.ts` - 500 错误通用中文文案

**问题**：路由级兜底 handler 返回 `err.message`，可能透出内部细节。

**修改**：
- `console.error` 日志记录原始错误信息与 requestId
- 将 `message` 改为 `'聊天服务暂时不可用，请稍后再试'`
- 保持 HTTP 状态码 500，不吞掉状态码

### 4. normalizeErrorBody 三种输入形状的转换例子

**形状1：扁平 `{code,message}`（无 success 字段）**
```
输入：{ code: 'VALIDATION_FAILED', message: '参数格式不对' }
输出：{ success: false, error: { code: 'VALIDATION_FAILED', message: '请求内容格式不对，请检查后重试', requestId: 'abc123' } }
```

**形状2：`{success:false,type:'error',content}`（保留 type/content，补 error）**
```
输入：{ success: false, type: 'error', content: '问题过长', error: { code: 'QUERY_TOO_LONG' } }
输出：{ success: false, error: { code: 'ASK_ERROR', message: '问题过长', requestId: 'abc123' }, type: 'error', content: '问题过长' }
```

**形状3：原有 `{success:false,error:{...}}`（行为不变）**
```
输入：{ success: false, error: { code: 'STORE_FAILED', message: '保存失败' } }
输出：{ success: false, error: { code: 'STORE_FAILED', message: '反馈没能保存下来，请稍后再试', requestId: 'abc123' } }
```
