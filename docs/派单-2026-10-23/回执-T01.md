## 四个问题的修复详情

### 1. 游客次数不刷新
**位置**：`ChatView.vue` 第 418–421 行（`onLiveUpdate` 函数末尾）  
**改法**：每轮问答流结束（`!live.streaming` 分支）后，若未登录，自动调用 `loadGuestUsage()` 重新拉取剩余次数。

```ts
// 问题 1 修复：每轮问答结束后，未登录则刷新游客剩余次数
if (!isLoggedIn.value) {
  void loadGuestUsage()
}
```

---

### 2. 次数用完 / 游客问答关闭时仍能点发送
**新增计算属性**（第 124–133 行）：`guestCanAsk` —— 综合判断“已登录 / 游客开关 / 剩余次数”。

```ts
const guestCanAsk = computed(() => {
  if (isLoggedIn.value) return true
  if (!guestAiOpen.value) return false
  if (guestUsage.value && guestUsage.value.remaining <= 0) return false
  return true
})
```

**发送按钮禁用条件**（第 1068 行）：加入 `|| !guestCanAsk`  
**回车键拦截**（第 688–698 行 `onKeydown`）：未登录且不可问时弹提示“游客今日提问次数已用完，登录后不受限制”并返回。  
**send 入口二次拦截**（第 634–638 行）：同理给出中文提示并返回 `false`。  
已登录用户完全不受影响。

---

### 3. 答不上来时仍挂 3 份不相关引用
**Store 层清空**（`useChatStreamStore.ts` 第 248–252 行）：`noAnswer` 分支里显式 `live.sources = []`。

```ts
if (!live.text) {
  live.noAnswer = true
  live.text = NO_ANSWER_TEXT
  live.sources = [] // 无答案时不挂来源条
}
```

**界面写入层过滤**（`ChatView.vue` 第 367–374 行 `paintLive`）：仅当 `!live.noAnswer` 时才写入 `sources`。

```ts
if (!live.noAnswer && live.sources.length > 0) msg.sources = live.sources
```

**模板层隐藏**（第 970–971 行 `citebar` 按钮 `v-if`）：增加 `&& !m.noAnswer`。

```vue
v-if="!m.failed && !m.noAnswer && m.sources && m.sources.length > 0"
```

历史消息经 `parseStoredAnswer` 解析出 `noAnswer: true` 的，同样不显示引用条（复用同一套 `m.noAnswer` 判断）。正常有答案的回答保留引用，未误伤。

---

### 4. 分享对话文案误导
**按钮 title**（第 1020 行）：`title="复制本机对话链接（仅本机可打开）"`  
**成功提示**（第 813 行 `shareConversation`）：`ElMessage.success('已复制本机对话链接（仅本机可打开）')`  
删掉了原来承诺“打开就是这条对话”的误导性措辞，不改后端、不新增接口。
