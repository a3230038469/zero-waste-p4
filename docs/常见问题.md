# 常见问题（开发期持续补充）

## 一、密钥相关
**Q：`.env` 提交上去会怎样？**
A：绝对不要提交。`.gitignore` 已经排除它。真实密钥只在自己电脑的 `backend/.env` 里，仓库里只有 `backend/.env.example`（占位符）。

**Q：我要写死的接口地址吗？**
A：不要。地址、密钥统一从 `.env` 读。

## 二、前后端怎么对接
**Q：前端怎么拿数据？**
A：只调自建后端（`localhost:4000`），不直接连引擎。

**Q：字段名叫什么？**
A：照 `docs/接口约定.md` 抄，**不要自创别名**。前端写 `title`，后端就不能返回 `name`。

## 三、协作
**Q：我能改别人的文件吗？**
A：不能。只改自己负责的文件（见文件头的"负责人"注释）。要动别人的，群里先说。

**Q：两个人同时改了同一个文件怎么办？**
A：这是分支制的意义——各自在自己分支上改，合的时候冲突由组长交给对应的人解。

**Q：接口还没好，前端怎么开发？**
A：先摆假数据把页面做出来，接口好了再替换成真实请求。**不要干等。**

## 四、引擎（WeKnora）
**Q：引擎要改吗？**
A：不改，一行都不改。我们只用它的 HTTP 接口。

**Q：引擎能暴露到公网吗？**
A：不能。它只在内网，网站是唯一对外入口。
