## 2. 七种交互态（公共类已内置，页面直接用）

| 状态 | 公共类 / 选择器 | 视觉表现 |
|---|---|---|
| 悬停 hover | `.zw-card--clickable` / `.zw-link` | 卡片上浮 2px + 阴影升一级 + 描边加深；链接变 `--zw-green-deep` |
| 按下 active | **全站兜底** `:where(a, button, input[type=button\|submit], [tabindex]):active`（2026-10-20 补） | 下沉 1px，120ms；卡片/链接有专门写法，组件自己写的 `:active` 优先级更高会覆盖兜底 |
| 键盘焦点 focus-visible | 全站 `a/button/input/select/textarea/[tabindex]` 自动生效 | 统一焦点环 `--zw-focus-ring`，鼠标点击不出现、Tab 才出现 |
| 禁用 disabled | `.zw-disabled` 或原生 `[disabled]` | 透明度 0.5 + `not-allowed` 光标 + 不响应悬停 |
| 加载 loading | `.zw-skeleton` + Element 按钮 `loading` 属性 | 骨架屏波浪占位；按钮转圈并禁重复提交 |
| 空态 empty | `.zw-empty`（内含 `__title`/`__desc`，可配出口按钮） | 图标 + 一句人话 + 一个出口 |
| 错误 error | `.zw-error`（内含 `__title`/`__desc`/`__retry`） | `--zw-danger` 文字 + 原因一行 + 重试按钮 |

Element Plus 对齐：输入框焦点环、按钮悬停加深、表单错误文字均已统一走本站令牌（见 global.css 第 8 节）。

## 3. 无障碍底线（验收会看）

- 正文与背景对比度 ≥ 4.5:1；大字号 ≥ 3:1
- 键盘 Tab 走完全流程，焦点始终可见
- 移动端点击区 ≥ 44×44px
- 图片有 `alt`；表单控件有 `label`；纯图标按钮有 `aria-label`
- 状态不能只靠颜色区分（配合图标或文字）

## 4. 页面接入规则

1. **只许用令牌值**：新写的字号/间距/圆角/阴影/时长一律 `var(--zw-*)`，禁止再出现新的硬编码值
2. **可点卡片加 `--clickable` 修饰类**，不要在页面里自己写 hover
3. 列表加载用 `.zw-skeleton`，无数据用 `.zw-empty`，请求失败用 `.zw-error`
4. 逐页接入时按人认领，改公共文件（global.css / tokens.css）先在群里说一声

## 5. 空态与错误态的判定边界（2026-10-20 补）

这是最容易写错的一处，判断标准只看**数据本身**，不看界面长得像不像：

| 情况 | 该用 | 不该用 |
|---|---|---|
| 请求成功，但结果集为空（筛选/搜索没命中） | `.zw-empty` + 出口（清筛选 / 换词 / 问 AI） | `el-empty`、错误态 |
| 请求失败 / 超时 / 接口 5xx | `.zw-error` + 原因 + **重试按钮** | 空态（会让用户以为"就是没有数据"） |
| 资源不存在（详情页 404、非法 id） | `.zw-empty`（说清"不存在或已下架"）+ 返回出口 | 错误态（重试也没用） |

**禁止再用 `el-empty` / `el-result`**：Element 的默认插画与灰蓝色系跟本站绿色主题不搭，
且自带一套间距字号，会破坏统一。全站已无遗留（2026-10-20 清完 5 处）。

反面教材：`InsightsView` 原本用 `el-empty description="暂时取不到统计数据"` +
「重新加载」按钮——语义是错误态却套了空态的壳，用户会以为统计本来就是空的。

## 6. 格式化工具陷阱（2026-10-20 补）

`prettier --write` 会重排 `.vue` 模板，**包括把 `v-on` 内联语句折行**。折行时它会删掉
语句之间的分号，而 Vue 模板把换行当空白，于是一行变两句直接语法错误：

```html
<!-- 格式化前（合法） -->
@click="activeType = t.value; onFilterChange()"

<!-- 格式化后（Vue 编译报错：Unexpected token） -->
@click="
  activeType = t.value
  onFilterChange()
"
```

实际后果：`/shelf` 整页白屏，而 `lint` 与 `vue-tsc --noEmit` **都是绿的**。

规矩：

1. 模板里**不写多语句内联处理器**，一律抽成方法：`@click="selectType(t.value)"`
2. `verify` 必须包含 `build`（vite build 才会真正编译模板），已加进脚本
3. 跑完 `format` 之后，至少要跑一次 `npm run verify`，不要只看 lint

## 7. 已知硬编码例外（2026-10-20 补）

`npm run audit:tokens` 会报「hex 45 / rgba 23」。这些数字里有一部分是**正常的**，
不追平到 0 是刻意的，免得为了指标好看去改真实设计：

| 位置 | 值 | 为什么不换成令牌 |
|---|---|---|
| `global.css` `:root` | 25 处 hex | 令牌源头本身，这里就该写真实色值 |

| `DocCard.vue` `.type-*` | `#5a6ea8` `#7a5aa8` `#a85a7a` | 资料**类型标识色板**（靛蓝/紫/玫红）。要不要进令牌取决于「类型配色」是否要全站统一，属设计决策，等设计确认再加 |
| `DocDetailView.vue` | `#8a5a12` | 深琥珀**文字**色。`--zw-amber`(#c8871f) 太亮，文字对比度不达 AA，所以单独取深一档；要收编得先加 `--zw-amber-deep` |
