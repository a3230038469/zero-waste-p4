## 当日更正（原「已知未修」一节已作废）

原文写「`chat/store.ts` 用了 Prisma 未生成的 model，`verify:all` 会失败」。
**实际不是代码问题**：`schema.prisma` 里 `Conversation`(L41) / `Message`(L52) 都在，
是本机安全软件拦了 `prisma generate` 的删除动作，生成的 client 成了空壳。

修法：`npm run prisma:generate`（若仍报错，先删 `node_modules/.prisma` 再跑）。
修完后 `npm run verify:all` 全绿，`verify` 也已恢复为包含 backend typecheck 的完整版。

真正遗留的只有性能项：`index-*.js` 1.12MB（gzip 372KB），vite 有 chunk 体积警告，
建议单独任务卡做 `manualChunks` 拆分。
