## 基础
- [ ] 后端 `/health` 返回 `{"ok":true}`
- [ ] 前端能打开，页面不报错

## 首页与问答（B07）
- [ ] 首页能看到，文案正常
- [ ] 右下角有问答气泡，点开能对话
- [ ] 点示例问题 → 自动提问并得到回答
- [ ] 问一个知识库里有资料的问题 → 回答带内容
- [ ] 问一个库里没有的问题 → 不会崩

## 注册登录（B02）
- [ ] 注册新账号 → 成功
- [ ] 缺字段注册 → 被拦并提示
- [ ] 重复手机号注册 → 被拦
- [ ] 登录 → 成功
- [ ] 导航栏显示"XX，你好"
- [ ] 刷新页面 → 登录态还在

## 书架（B05/B03）
- [ ] 书架能打开，能看到资料列表
- [ ] 按类型切换 → 结果变化正确
- [ ] 按机构筛选 → 计数与下拉一致
- [ ] 按年份筛选 → 计数与下拉一致
- [ ] 按主题筛选 → 计数与下拉一致
- [ ] 搜一个真实文件名片段 → 命中
- [ ] 搜一个乱词 → 零结果 + 「试试问 AI」按钮出现
- [ ] 点「试试问 AI」→ 问题被预填进问答窗口
- [ ] 翻到第 2 页 → 数据不重复

## 详情与下载（B06）
- [ ] 点一份资料 → 进详情页
- [ ] 元数据显示正确（标题/机构/年份/类型/标签）
- [ ] 小文件能在线预览
- [ ] 未登录点下载 → 跳登录页
- [ ] 登录后点下载 → 文件下载成功
- [ ] 下载的文件名格式为「年份-机构-标题」

## 移动端
- [ ] 手机（或浏览器缩到手机宽度）打开首页 → 能看能用
- [ ] 书架在手机宽度下不横向滚动
- [ ] 导航栏在手机宽度下不错位
