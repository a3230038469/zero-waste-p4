## 二、功能清单（派单正文）

### B00 工程地基 · 志广

- [x] 仓库 + 目录（本仓库）
- [x] 前端/后端能启动、lint 零报错
- [x] 后端路由按人分文件（`docs.ts` / `auth.ts` / `embed.ts`）
- [x] `.env.example` + `.gitignore`
- 验收：`npm run dev:backend` 后 `/health` 返回 `{"ok":true}`；前端 5173 见占位页

### B01 引擎连接 · 韶茹

1. 能连上引擎（地址、密钥从 `.env` 读，不写死）
2. 能取知识库**文件列表**（标题/机构/年份/类型/标签/大小）
3. 能按关键词**检索**
4. 能取单份文件的**详情、预览、下载**
5. 出错要给清楚提示，不能白屏崩

验收：调用后返回真实文件列表（至少 1 条含标题）；密钥不出现在任何提交文件里。

### B02 用户板块 · 月月

1. **注册**：五字段（姓名/机构/职业/关注议题/电话）+ 密码
   - 缺字段、手机号格式错、密码太短 → 拦住并说明原因
   - 同一手机号不能注册两次
2. **登录**：手机号 + 密码，成功后保持登录态（关浏览器再开还在）
3. 登录后导航栏显示名字
4. 密码不能明文存
5. 注册页 + 登录页（可同页标签切换）

验收：缺字段能拦、重复手机号能拦、正确注册能登录、刷新不掉登录态、库里密码非明文。

### B03 资料数据 · 韶茹

1. 给前端**资料列表**接口：四维筛选 + 关键词搜索 + 分页（20/页）+ 排序
2. 提供**筛选项**接口（各维度值 + 数量），供前端画下拉
3. 搜不到要明确返回"没找到"（`zeroResult: true`）
4. **重点：筛选出来的条数必须和选项里标的数量一致**

验收：四个维度筛选都准；搜索命中/零结果都对；翻页不重复；`page=0` 回落第 1 页。

### B04 网站框架 · 丁梓柔

1. 四个页面能互相跳：`/` `/shelf` `/doc/:id` `/auth`
2. 顶部导航栏（每页都有）：站点名 + 链接 + 右上角登录态
3. 统一视觉基调（零废弃主题，建议绿色系）
4. 统一请求封装（自动带登录凭证、统一错误提示）
5. 手机宽度下导航栏不错位

验收：四页都能开、导航一致、登录态显示对、375px 宽不错位。

### B05 书架页 · 丁梓柔

1. 顶部**类型切换**：全部 / 政策法规 / 案例工具 / 研究报告 / 标准规范
2. **筛选器**：机构、年份、主题（多选），**下拉项显示数量**
3. **搜索框**，回车搜索
4. **资料列表**：标题/机构/年份/类型/标签，点击进详情
5. **零结果处理**：显示"没有匹配的资料" + 「试试问 AI」按钮
6. **分页**：20 条/页
7. **加载中**显示骨架块，别白屏

验收：四维筛选各试一次且计数一致；搜索命中/零结果都对；翻页不重复；手机宽不横滚。

### B06 详情页 · 丁梓柔

1. **信息区**：标题、机构、年份、类型、标签、大小、来源
2. **在线预览** PDF；超 20MB → 提示"文件较大，建议下载后查看"；微信内 → 提示"请下载后用其他应用打开"
3. **下载按钮**：未登录显示「下载（需登录）」，点击跳 `/auth?redirect=/doc/:id`；登录后下载，**文件名「年份-机构-标题」**
4. 预览、下载动作要能被统计到

验收：信息正确；小文件能预览、大文件有提示；未登录下载跳登录且能回跳；文件名格式对。

### B07 首页 + AI 问答 · 瑞泽

1. 首页内容：一句话说明、能问什么引导、搜索框（回车跳书架）、已收录数量（**动态取，不写死**）
2. **示例问题 3–6 条**，点击后**自动填到问答窗口并发送**
3. **嵌入 AI 问答窗口**：右下角气泡，点开能对话；**访客不用注册也能问**
4. **降级提示**：连不上时提示"AI 暂时不可用"，不能一直显示"已就绪"却点不开

验收：首页文案和搜索框可用；点示例问题能自动提问并得到回答；真实问一轮能通；挂掉有提示。

### B08 问答凭证 · 韶茹

1. 后端持有引擎给的长期凭证（放 `.env`）
2. 提供接口：前端来要钥匙 → 校验来源合法 → 换 30 分钟临时钥匙 → 返回
3. 留开关 `REQUIRE_LOGIN_FOR_ASK`（默认 `false`），改一行配置即可切换

验收：接口返回带有效期的钥匙；来源不合法被拒。

### B09 内容准备 · 静柔

1. 收集 **15–20 份公开的**零废弃主题 PDF（政策、研究报告）；**严禁含个人信息的文件**
2. 做 Excel 元数据表：标题/机构/年份/类型/主题
3. 导入知识库
4. 执行冒烟清单（见 [`冒烟测试清单.md`](./冒烟测试清单.md)）
5. 记录失败项发群里，**不要自己改别人的板块**

验收：库里 ≥15 份公开资料；元数据表齐全；冒烟清单走完且问题如实记录。
