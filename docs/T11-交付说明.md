## 九、几个需要主控拍板 / 知情的取舍

1. **新增了一条公开只读接口 `GET /api/guest/permissions`**（任务单只列了 admin 那两条）。
   没有它，公众页面拿不到开关 → 2.4 的「按配置置灰」在浏览器里根本实现不了。
   它只返回一排布尔值与一个数字，**不含任何密钥/口令/用户数据**。已按契约先行写进 `docs/接口约定.md`。
2. **游客每日上限的「游客标识」用 `sha256(IP + User-Agent)`**。
   - 不引依赖、不落原始 IP（文件里只有 16 位哈希）；
   - ⚠️ 已知取舍：**同一单位出口 IP 的访客共用一个额度**（学校/机构网尤其明显）。想更准就得引入账号或验证码，那是另一个量级的需求。
3. **403 状态码的选择**：`aiAsk` 关闭与次数用满都用 **403 + 各自的 code**（任务单允许 401/403），理由是补救动作都是「登录」；
   反馈整批被拒也用 403。混批时改为 **201 + 在 `rejected[]` 里如实回报**，不整批失败。
4. **额度在开流前扣减**：被拒的请求不消耗额度；引擎中途报错仍算用掉（限流防的是刷，不是失败补偿）。
5. **`REQUIRE_LOGIN_FOR_ASK` 保留但降级**为 `aiAsk` 的**初始默认值**（任务单第七节要求）。
   即：环境变量为 true 时，首次打开设置页看到「AI 问答」是关的；老师保存过一次之后，一律以设置页为准。

## 十一之二、`POST /api/track` 的旁路回归（白名单与部分成功口径没被本轮带坏）

同一批三事件（`page_view` + `feedback_submit` + 一个不在白名单里的「瞎写的」）：

```
feedback 开着（默认）→
  {"success":true,"accepted":2,"rejected":[{"index":2,"code":"UNKNOWN_EVENT","message":"第 2 条事件名不在白名单：瞎写的"}]}   HTTP 201

把 feedback 关掉后，同一批 →
  {"success":true,"accepted":1,"rejected":[
      {"index":1,"code":"FEEDBACK_CLOSED","message":"意见反馈需要登录后才能提交，请先登录"},
      {"index":2,"code":"UNKNOWN_EVENT","message":"第 2 条事件名不在白名单：瞎写的"}]}                                  HTTP 201
```

即：白名单校验照旧、部分成功口径照旧、**下标仍与前端发来的一致**（被摘掉一条不影响对账）；
只有「未登录 + 反馈已关」这一种组合会新增一条 `FEEDBACK_CLOSED`。

## 十二、留给主控复跑的最小步骤

```powershell
# 1) 起一个 4100 的自测后端（不要用 4000）
cd backend
$env:PORT='4100'; npx.cmd tsx src/index.ts

# 2) 口令取出来（不回显真值）
$admin=((Select-String -Path .env -Pattern '^ADMIN_STATS_TOKEN=(.*)$').Matches[0].Groups[1].Value).Trim()

# 3) 读开关 / 写开关（回读校验）
curl.exe -H "X-Admin-Token: $admin" http://localhost:4100/api/admin/guest-permissions
Set-Content $env:TEMP\gp.json '{"download":true,"preview":false,"aiAsk":false,"feedback":false,"aiAskDailyLimit":1}' -NoNewline
curl.exe -X PUT -H "X-Admin-Token: $admin" -H "Content-Type: application/json" --data-binary "@$env:TEMP\gp.json" http://localhost:4100/api/admin/guest-permissions

# 4) 关键：不带 Authorization 直接 curl（应 403，不是 200）
$doc=(curl.exe -s "http://localhost:4100/api/docs?pageSize=1" | ConvertFrom-Json).items[0].id
curl.exe -o NUL -w "download=%{http_code}`n" "http://localhost:4100/api/docs/$doc/download"   # 403
curl.exe -o NUL -w "preview=%{http_code}`n"  "http://localhost:4100/api/docs/$doc/preview"    # 403（preview 已关）
Set-Content $env:TEMP\ask.json '{"query":"零废弃"}' -NoNewline
curl.exe -X POST -H "Content-Type: application/json" --data-binary "@$env:TEMP\ask.json" http://localhost:4100/api/ask   # 403 GUEST_ASK_CLOSED
# （PowerShell 里给 curl 传带引号的 JSON 会被吞掉，必须走文件：--data-binary "@file"）

# 5) 使用明细（省略 date = 今天）
curl.exe -H "X-Admin-Token: $admin" http://localhost:4100/api/admin/usage-detail

# 6) 测完：恢复默认值并清掉运行时文件
Set-Content $env:TEMP\gp.json '{"aiAsk":true,"aiAskDailyLimit":5,"preview":true,"share":true,"feedback":true,"download":false}' -NoNewline
curl.exe -X PUT -H "X-Admin-Token: $admin" -H "Content-Type: application/json" --data-binary "@$env:TEMP\gp.json" http://localhost:4100/api/admin/guest-permissions
Remove-Item backend/data/guest-permissions.json, backend/data/guest-ask-usage.json -ErrorAction SilentlyContinue
```

> ⚠️ 若主控用真机 4000 复跑第 4 步，请记得**先在设置页/接口把开关切过去**，测完再切回默认：
> 本机交付状态是「配置文件已删 = 全默认」，即**游客能预览/能分享/能反馈，不能下载**，问答上限 5 次。
