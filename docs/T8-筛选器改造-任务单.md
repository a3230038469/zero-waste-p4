## 二、要做的三件事

### 1️⃣ 机构筛选器：过滤 + 搜索框

**后端**（`backend/src/routes/docs.ts`）
- `orgs` 只返回 **出现 ≥2 次**的机构（实测：≥3 次 27 个 + =2 次 21 个 = **48 个**）
- ⚠️ **但用户仍要能搜到那 295 个低频机构** → 因此：
- **新增一个 `q` 参数的机构过滤接口**：`GET /api/docs/facets?orgSearch=关键字`
  - 模糊匹配机构名（大小写不敏感），返回命中机构 + 各自的资料数
  - 上限 20 条

**联合发文串的处理（关键）**
一个 `org` 值里可能塞了多个机构，分隔符**不止顿号**（实测全部出现过）：

| 分隔符 | 说明 |
|---|---|
| `、` | 最常见 |
| `空格` / `**\xa0`（不换行空格）** | 🔴 **两个都要处理** —— JS 里 `\s` **默认不含 `\xa0`**，要用 `\p{Zs}` 或显式加 |
| `+` | 例：`原国家安全监管总局 + 工信部、公安部` |
| `,`（半角逗号） | 例：`Food and Agriculture Organization of the United Nation, UNEP` |
| `\n`（换行） | 有一个值里含换行符 |

→ **先把所有 Unicode 空白压成普通空格，再按上面 5 种分隔符切分**，切出多个机构时：
- 计入「联合发文」计数
- 下拉里**不单独列这个长串**，改为显示 `机构A + 机构B + …`（最多 2 个 + 「等N家」）

**别名归一（只做显示层，不改数据）**

| 主名 | 等价写法 |
|---|---|
| 联合国环境规划署 | UNEP |
| 世界自然基金会 | WWF |
| 国家发展和改革委员会 | 国家发改委、发改委 |
| 国家市场监督管理总局 | 市场监管总局 |
| ⚠️ 环境保护部 / 生态环境部 | **不合并** —— 2018 机构改名，历史文件用旧名是事实，合并反而失真 |

### 2️⃣ 书架加「所属方向」筛选器

- 数据源：`custom_metadata.srcTable`，只有 **2 个值**：`知识查询（零废弃）`（480）、`知识查询（化学品）`（123）
- 中文显示名建议：**零废弃** / **化学品与健康**
- 在 `buildFacets` 里加一个维度，**默认不过滤**

### 3️⃣ 来源卡片显示「机构 / 年份」

**关键情报（对方对话 A 实测纠正，原先的说法是错的）**：

引擎 `agent-chat` 的引用数据里，**有** 元数据，位置是：

```
data.references[]  ← 🔴 不是顶层的 knowledge_references（顶层少 2 个字段）
```

每条引用里的 `knowledge_custom_metadata` **直接带** org / year / type / tags / srcTable。

⚠️ **格式是「YAML 风格字符串」，不是 JSON**：

```
org: 宁波市商务局
srcTable: 知识查询（零废弃）
tags: 垃圾分类
type: 政策法规
year: 2020
```

**解析要点**：按行拆 `key: value`，**⚠️ 值里可能含冒号，不能按第一个冒号切一刀**（要用「第一个 `: `（冒号+空格）」切）。

**改动点**：`backend/src/weknora/agent-sse.ts` 里做 references → `sources` 的映射
- 目前是用 `knowledge_id` 去书架列表本地关联 org/year（**可以保留做兜底**）
- **新增**：优先读 `knowledge_custom_metadata`（更准、更省）

前端 `frontend/src/api/ask.ts` 的 `AskSource` 类型加上**可选**字段 `org?` / `year?`，并透传给卡片组件。
