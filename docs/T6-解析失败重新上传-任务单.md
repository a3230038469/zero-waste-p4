# T6 · 解析失败一键「重新上传」（删旧+重传，不走重解析）

> 主控：小志；执行：OpenCode；验收：主控亲测
> 服务在跑：后端 4000（tsx watch）/ 前端 5173 / 引擎 8080。**不重启、不动 8080。**

## 需求

老师后台资料列表里，**解析失败**的行提供「重新上传」按钮。一键完成：**从引擎取回原件 → 删除旧记录 → 重新上传 → 元数据原样带回**。不用引擎的"重新解析"（重解析走异步任务、状态复杂，本需求就是要确定性路径）。老师本地不需要存原件。

## 后端

`backend/src/routes/admin.ts` 新增 `POST /api/admin/knowledge/:id/reupload`（`assertAdmin` 鉴权，鉴权在前）：

1. 从引擎取原件：`POST /api/v1/knowledge-bases/{kbId}/knowledge/batch-download` body `{ids:[id]}` → zip 字节 → 用**已有的** `weknora/zip.ts` 拆出第一个文件条目（跳过目录条目），得到 `{name, data}`
2. 读旧资料的 `custom_metadata`（引擎单条接口 `GET /api/v1/knowledge/{id}`，解开外层 data）
3. 删旧记录：`DELETE /api/v1/knowledge/{id}`
4. 重新上传：`POST /api/v1/knowledge-bases/{kbId}/knowledge/file`，FormData（`file` 二进制 + 文件名）；若第 2 步拿到非空 metadata，上传成功后 `PUT /api/v1/knowledge/{newId}` body `{custom_metadata}` 原样带回（注意：值只能是字符串/数字/布尔，数组会被拒——沿用现有处理）
5. 清除列表缓存（`invalidateEngineListCache()`）
6. 返回 `{success, data:{id, fileName, metaRestored:boolean}}`

错误处理（每步都要有，返回中文友好 message）：
- 引擎不可达/超时 → 502「引擎暂时连不上」
- 旧记录不存在 → 404「这份资料已经不在库里了」
- zip 拆不出文件（空 zip/全目录条目）→ 502「没能从引擎取回原件」
- 上传失败 → 502，带上引擎原文摘要

引擎调用复用 `weknora/index.ts` 现有的封装风格（不要新造 HTTP 层）；引擎密钥从 `.env` 读（不硬编码）。

## 前端

`frontend/src/views/AdminKnowledgeView.vue`：
- `parseStatus === 'failed'` 的行，操作列加「**重新上传**」按钮（link 样式，和现有下载/删除一致）
