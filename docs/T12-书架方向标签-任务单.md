## 一、目标（一句话）

书架页顶部现在排了一长串**类型**标签（9 个），改成 **3 个「方向」标签**（全部 / 零废弃 / 化学品与健康）；
原来那些类型**不丢**——它们在工具栏的「类型」下拉里，**跟着所选方向自动只列该方向的类型**。

## 三、改动清单

### T12-A 顶部标签行：类型 → 方向

1. 把 `typeTabs`（类型标签）换成 **`directionTabs`（方向标签）**：
   - 第 1 项：`{ value: '', label: '全部', count: <facets.srcTables 各 count 之和> }`
   - 之后每项：`{ value: <srcTable 数据原值>, label: <后端给的 label>, count: <该方向份数> }`
   - **一律用后端给的 `label`**（`零废弃` / `化学品与健康`），**不许在前端写死中文名**
2. 🔴 **降级**：`facets.srcTables` 为空数组时 → **整条标签行不渲染**（老快照数据源没有方向，摆出来就是一个筛不中的假选项）
3. 点击行为：单选语义（点一项即按该方向筛，点「全部」= 清除方向筛选）
4. 模板结构、class 名尽量沿用 `type-row` / `type-tab` / `is-active` / `tab-count`（CSS 已写好，别新建一套）
5. 🔴 **保留** `role="tablist"` 与 `aria-label`（无障碍），`aria-label` 文案改成「资料方向」

### T12-B 工具栏：删掉重复的方向下拉

1. 删掉工具栏里那个「所属方向」下拉（`class="filter-src"` 那一块）——它已经提升为顶部标签
2. 其余筛选器**位置与行为全部不动**：机构（文本式，回车生效）/ 主题（多选）/ 类型（单选）/ 年份（多选）/ 排序 / 关键词搜索
3. 「类型」下拉**保持原样**（它现在会自动跟着方向变，见第二节事实 4）—— 不需要额外加过滤代码
4. 「当前筛选」行里的 chip：**方向不再单独生成 chip**（顶部标签已经高亮表达了同一件事，重复显示会让人以为筛了两次）
   - 但 `resetAll()`（全部清除）**必须仍然清掉方向**

### T12-C 跨方向切换时清理失效的类型

**问题**：用户在「零废弃」下选了类型 `案例工具`，再切到「化学品与健康」——那个类型在该方向下不存在，会得到**空结果**，用户不知道发生了什么。

**要求**：切换方向后，若当前已选的类型**不在新方向的类型里** → **自动清掉类型筛选**（静默清掉即可，不要弹窗）。

**实现注意（重要）**：`facets` 是异步取的 —— 要等**新方向**的 `facets` 回来后再校验，**不能拿旧方向的类型列表判断**。

### T12-D 文案

顶部那句说明（模板 219-221 行附近）里「可按类型切换」→ 改成「**可按方向浏览**」，其余不变。
