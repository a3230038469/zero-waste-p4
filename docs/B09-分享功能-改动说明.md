# B09 · 分享功能改动说明（分享二维码 + 转发卡片）

> 负责板块：公众互动模块 · 分享（B09）
> 日期：2026-10-13　分支：`B09-public-module`（与反馈功能同一分支，合并即可一并收）
> 零新增接口、零新增 npm 依赖、零新增埋点事件名。

---

## 一、做了什么（一句话）

详情页新增「**分享二维码**」弹窗（二维码 + 复制链接 + 保存 PNG），同时让**转发到微信/QQ/钉钉的链接卡片**显示每份资料的真实标题、摘要和配图——而不是现在那样，转哪份都只显示站名「零废弃知识库」。

## 二、为什么（两件事各自补了一个传播缺口）

**① 转发卡片没信息量（后端补）**
微信 / QQ / 钉钉转发链接时，是由它们的抓取程序读 HTML 里的 `<title>` / `og:*` 标签拼卡片，**这个程序不执行 JS**。我们是 Vue 单页应用，`dist/index.html` 标题永远是站名——转 617 份里任何一份，卡片都一样，没有缩略图。公益传播主要靠微信群，这个缺口必须补。做法：后端回 HTML 时按路径注入资料级 meta（`backend/src/share/meta.ts`）。

**② 线下场景没有链接可发（前端补）**
开会、摆摊、发传单时没人打一条链接。详情页加「分享二维码」，扫码直达该资料；可导出 PNG 交给物料设计。

## 三、改动清单

| # | 文件 | 新增/修改 | 内容 |
|---|---|---|---|
| 1 | `backend/src/share/meta.ts` | 新增 | meta 组装与注入：按数据来源找资料 → 生成标题/摘要/封面 → 整段替换 index.html 里标记区 |
| 2 | `backend/src/index.ts` | 修改 | SPA 回退从 `sendFile` 改为「注入后返回」，**任何异常退回原 sendFile**，行为与改前完全一致（见文件内 B09 注释，含回退方法） |
| 3 | `frontend/index.html` | 修改 | 加 `<!-- share-meta:start/end -->` 标记区与默认标签（首页/未注入页用） |
| 4 | `frontend/public/share-cover.png` | 新增 | 默认分享封面 600×600（只有站名+四个类型枚举，未画任何未经确认的机构标识） |
| 5 | `frontend/src/components/ShareDialog.vue` | 新增 | 分享弹窗：二维码（SVG）、链接框（打开即全选）、复制链接、保存二维码 PNG、微信/线下/登录提示 |
| 6 | `frontend/src/utils/qrcode.ts` | 新增 | 二维码工具：矩阵生成（UTF-8）、SVG 路径、canvas 导出。容错等级 M，自带 4 模块静区 |
| 7 | `frontend/src/utils/vendor/qrcode-generator.mjs` + `.d.mts` + `.README.txt` | 新增 | 第三方库**原样内置**（MIT，作者 Kazuhiko Arase，npm `qrcode-generator@2.0.4` 的 dist 文件，未改一行，出处写在文件头注释） |
| 8 | `frontend/src/views/DocDetailView.vue` | 修改 | 加「分享二维码」按钮 + 弹窗；进详情页把标签页标题换成资料名，离开还原 |
| 9 | `backend/.env.example` | 修改 | 登记 `SITE_BASE_URL`（公网部署配一次，卡片里的绝对地址才对） |

**为什么二维码库是「内置」而不是装依赖**：详情页生成二维码若调第三方接口，等于把「谁在看什么资料」发给外部服务，且断网就画不出来；而团队目前是网页上传协作，装依赖会动 `package.json` / `package-lock.json`，与并行改动极易冲突。内置单文件 MIT 实现最稳，README 与出处都放在 `vendor/` 里，以后 `npm i qrcode-generator` 可一键替换。

## 四、如实说明边界（评审前请先看这条）

- **能做到**：链接被抓取时，卡片标题 = 资料名、摘要 = 机构/年份/类型/主题（全部来自台账字段，不编内容）、配图 = 站点封面。QQ、钉钉、浏览器收藏/分享完全生效。
- **做不到（本次）**：微信里 100% 自定义卡片需要**公众号 JS-SDK 签名**（要已认证公众号 appid + 后端签名接口），当前项目没有这些资源。已按微信抓取规则把能给的都给了；如后续申请到公众号，在 `meta.ts` 基础上加签名接口即可，前端不用动。
- 本机预览/下载接口 404 是因为自测机只有 617 份的**索引**没有 PDF 原件，与本次改动无关。

## 六、对其他人的影响（就一条规矩）

`frontend/index.html` 里的 `<!-- share-meta:start --> … <!-- share-meta:end -->` 区段会被后端**整段替换**——要改默认卡片文案可以，但**两个注释标记必须保留**，否则替换失效。其余改动不触碰任何人的文件。

## 七、回退方法

- 前端：删掉 `ShareDialog.vue`、`utils/qrcode.ts`、`utils/vendor/`、`public/share-cover.png`，`DocDetailView.vue` 里删掉带「B09」注释的段落即可。
- 后端：`index.ts` 里把 `renderSpaHtml` 那段换回 `res.sendFile(path.join(distDir, 'index.html'))`（文件头注释里有原样写法），删 `share/meta.ts`，`index.html` 的标记区保留也不影响。
