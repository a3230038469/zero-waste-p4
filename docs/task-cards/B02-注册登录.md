## 一、目标

公众网站的用户体系：注册、登录、保持登录态。密码必须哈希存储，密钥不进 git。

## 二、契约（照抄，不自创）

| 用途 | 方法 + 路径 | 请求体 | 返回 |
|---|---|---|---|
| 注册 | `POST /api/auth/register` | 姓名 / 机构 / 职业 / 关注议题 / 电话 / 密码 | `201` 成功 |
| 登录 | `POST /api/auth/login` | 电话 / 密码 | `{ token }`，JWT 有效期 30 天 |
| 当前用户 | `GET /api/auth/me` | Header `Authorization: Bearer <token>` | 用户信息 |

错误码约定：

| 场景 | 状态码 | 说明 |
|---|---|---|
| 缺必填字段 / 手机号格式错 / 密码过短 | `400` | 响应体带具体原因，不是笼统"参数错误" |
| 手机号已注册 | `409` | — |
| 密码错误 | `401` | — |
| 无 token 访问 `/me` | `401` | — |

## 三、实现落点

| 文件 | 内容 |
|---|---|
| `backend/src/routes/auth.ts` | 三个接口实现（**只许改这一个文件**） |
| `backend/prisma/schema.prisma` | `model User`（五字段 + `passwordHash` + `phone @unique`） |
| `frontend/src/api/auth.ts` | 统一请求封装，自动带 token |
| `frontend/src/views/AuthView.vue` | 注册 / 登录同页标签切换 + 前端校验 |

## 四、验收命令

```bash
# 注册成功
curl -X POST localhost:4000/api/auth/register -H "Content-Type: application/json" \
  -d '{"name":"测试","org":"某机构","occupation":"研究","topics":"零废弃","phone":"13800138000","password":"test1234"}'
# 期望 201

# 重复手机号
# 期望 409

# 登录
curl -X POST localhost:4000/api/auth/login -H "Content-Type: application/json" \
  -d '{"phone":"13800138000","password":"test1234"}'
# 期望 { "token": "..." }

# 带 token 取当前用户
curl localhost:4000/api/auth/me -H "Authorization: Bearer <上面拿到的 token>"
# 期望 200

# 确认密码是哈希
sqlite3 backend/prisma/dev.db "SELECT passwordHash FROM User LIMIT 1;"
# 期望以 $2a$10$ 开头，不是明文
```

## 五、已知坑

- **`docs.ts` 与 `embed.ts` 严禁动**——那是韶茹的文件，动了就撞车。
- Prisma `generate` 有时会产出空 stub（本机安全钩子误删），症状是 `Property 'user' does not exist`。解法：`rm -rf node_modules/.prisma && npx prisma generate`。
- 密钥只写 `backend/.env`，**不进代码 / 不进 git / 不进文档**。

## 六、墓碑候选

本卡未产生一次性脚本或调试接口。注册登录的回归测试属安全网，**不删**。
