设计说明（方案 A）

  • 头像 = 印章：把头像做成一方方形朱文/墨文小章，对应设计方案里"印章只用一处"的规则。方章 4px 圆角，内框一道细线，像刻好的章。颜色用墨绿，不用朱红（朱红留给"支持我们"）。
  • 名字用宋体，展开箭头换成三根由长到短的竖线，呼应 logo 的"巷道"母题，代替通用三角。
  • 下拉卡 = 名帖：宣纸色底、一道朱线、虚线分隔身份区与菜单，菜单用"壹 贰 叁"序号 + 点线目录，沿用资料库和信息公开的目录语言。
  • 退出登录降为页脚小字，避免在菜单里像一颗危险按钮。
  • 方案 B：圆形头像外加一道环形进度线，把"循环"具象化（进度来源待定，不能编造数字）。仅作备选。
  • 没有阴影堆叠、没有渐变，圆角 ≤ 4px，与新版 UI 令牌一致。
  • 内容字段保持不变：名字 / 机构 / 个人资料 / 我的投稿 / 意见反馈 / 管理台（仅管理员）/ 退出登录。

  • 选 A 还是 B？A 更有机构感，B 更接近"循环"语义。
