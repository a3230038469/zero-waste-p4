# T4 · 问答体验升级（来源卡片 + Markdown 渲染 + 趣味等待）

> 主控：小志（组长）；执行：OpenCode；验收：主控亲测
> 服务已在跑：后端 4000（tsx watch 热重载）/ 前端 5173 / 引擎 8080。**不要重启任何服务、不要动 8080。**

## 背景

回答流是 SSE（`POST /api/ask` → text/event-stream），事件格式见 `backend/src/weknora/index.ts` 的 `askKnowledgeBase()` 与 `backend/src/routes/ask.ts`。模型回答里**已经带引用标记**：

```
<kb doc="382-厨余垃圾全生命低碳管理综述.pdf" chunk_id="..." kb_id="..." />
```

目前前端 `HomeAskWidget.vue` 用 `renderAnswer()` 把这些标记**剥掉扔了**，正文用 `{{ }}` 纯文本插值——Markdown 符号全部裸奔。

## 三件事

### 1. 来源卡片（可点击链接）

- 后端：在 `ask.ts` 的 SSE 流里新增一个结束前事件 `{ "type":"sources", "items":[{ "name":"<资料名>", "url":"/doc/<id>" }] }`。
  - 解析回答文本里的全部 `<kb doc="..."/>` 标记（去重）；
  - `doc` 文件名 → 资料 id：用 `weknora/index.ts` 里 `listFiles()` 的缓存按 `fileName`/`title` 匹配（去掉 `.pdf` 等扩展名再比对，容忍空格差异）；匹配不到的条目跳过（不要放死链接）；
  - 最多返回 5 条。
- 前端：`HomeAskWidget.vue` 收到 `sources` 事件后，在该条回答气泡底部渲染一排「来源」小卡片（chip 样式），点击用 `router.push(url)` 跳到详情页（详情页自带预览/下载按钮，就是用户要的"点了一直达预览下载"）。
- 剥离正文里的 `<kb .../>` 标记逻辑保留（正文里不再出现尖括号噪音）。

### 2. Markdown 渲染

- 新增依赖：`marked`（渲染）+ `dompurify`（防注入），**只许这两个**，装在 frontend。
- 回答气泡改 `v-html` 渲染：`DOMPurify.sanitize(marked.parse(text))`；正文先剥 `<kb/>` 标记再渲染。
- 配套样式（该文件的 `<style>` 内）：气泡内 h1-h4 缩小到适合聊天的字号、`table` 加边框和斑马纹、`code`/`pre` 浅灰底、`a` 用主题绿。
- **用户提问的消息保持纯文本**（用户的输入不要渲染）。
- `npm run typecheck` 必须过。

### 3. 等待彩蛋（检索中的趣味文案轮播）

- `busy` 且尚未收到任何正文时，把现在的「正在查资料…」升级为**每 2.5 秒轮换一句**的趣味文案池，主题贴零废弃/环保/翻资料，幽默但克制，**不用 emoji**。示例风格（可以自己再写几条，共 10 条左右）：
  - 正在垃圾堆里翻找答案……
  - 翻到第 382 页了，快好了……
  - 正在给资料做垃圾分类（检索中）……
  - 厨余堆肥需要时间，答案也一样……
  - 正在给知识库做一次断舍离……
- 收到第一个正文片段后立刻停轮播（不准闪）。
- 用 `setInterval` + `onUnmounted` 清理，别留内存泄漏。

## 硬约束

- 不改 `.env`、不删文件、不引任务单之外的依赖、不动 8080 引擎与任何服务进程。
- 流式行为不变（SSE 逐字到达的体验保持）。
- `docs/接口约定.md` 追加 sources 事件一行；`docs/本地演示改动日志-2026-10-08.md` 末尾追加「阶段十五」三行小结。
- 完成后回报：改动文件清单（git status）、两次 typecheck 尾部输出、你发现但没覆盖的风险。

## 主控验收标准（验收时逐条打勾）

1. 问「厨余垃圾怎么处理」，回答出现真排版（标题/列表/表格），无裸 `**` 或 `|---|`
2. 回答底部出现可点击来源卡片，点了跳到对应 `/doc/:id` 详情页
3. 等待期间文案每 2.5 秒轮换、出字即停
4. 用户自己的提问不渲染 Markdown（输入 `*x*` 显示原样）
5. 前后端 typecheck 零错误
