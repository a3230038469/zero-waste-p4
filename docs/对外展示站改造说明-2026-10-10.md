# 对外展示站改造说明（2026-10-10）

> 背景：这个网站之后要作为**六尺巷基金会对外的展示与信息分享网站**。
> 这一版把「作业 demo 能跑通」的状态，推到了「可以给公众和合作方看」的状态：
> 页面结构按对外展示重排、真实数据做了面向展示的清洗、补上了站点级的信息交代（页脚 / 关于 / 数据概览）。
>
> 本文记三件事：**改了什么、依据是什么、还有什么要基金会拍板**。

---

## 一、一句话结论

- **数据要改，也改了 3 处**（都有据可查、可回退）：机构同义归一、化学品子库回填主题标签、重复内容标记。
- **页面要改，也改了**：原来的 4 页（首页/书架/详情/登录）扩成 6 页对外结构 ——
  首页改版、新增「数据概览」与「关于项目」、书架更名「资料库」并支持带筛选进入、详情页补相关推荐与重复提示。
- **另有 6 项涉及业务判断的，只列清单没动**（见第五节），需要基金会拍板。

## 二、站点结构（改后）

| 页面 | 路由 | 对外定位 |
|---|---|---|
| 首页 | `/` | 讲清「这是什么」+ 检索入口 + 数据速览 + 主题/类型入口 + 最近收录 + 关于与问答 |
| 资料库 | `/shelf` | 全部资料，支持类型切换、四维筛选（机构/年份/主题，下拉可搜索）、排序、关键词检索 |
| 数据概览 | `/insights` | 整库数据画像：年份分布、类型分布、主题分布、机构 Top 10、统计口径与局限 |
| 关于项目 | `/about` | 项目简介、怎么用、数据来源与口径、引用与转载、联系与共建 |
| 资料详情 | `/doc/:id` | 完整字段、在线预览、下载原件、复制分享链接、同主题推荐、重复副本提示 |
| 登录 / 注册 | `/auth` | 预览与下载需登录（沿用原设计） |
| 内部后台 | `/admin/*` | 资料管理、访问统计（**入口从主导航移到页脚**，见第四节） |

导航：首页 / 资料库 / 数据概览 / 关于项目 —— 四个入口对应访客的四种意图。

## 三、数据处置

### 3.1 总数口径（沿用 2026-10-10 上午的结论，未变）

**617 份**。台账 606 行 → 展开为 617 个文件；附件包 617 份；引擎快照 605 份（旧）。附件包是引擎的超集，无内容丢失。

### 3.2 这次实际改了什么

改动只落在**元数据**，原件一个字节都没动；旧索引与旧元数据都留了备份。

| # | 改了什么 | 影响面 | 依据 |
|---|---|---|---|
| R1 | **机构同义归一**：同一机构被「顿号 / 空格」写成两种，统一成占比高的那种写法 | 13 条记录（国标委 10 条、中共中央 1 条、中共中央办公厅 1 条） | 两种写法指向同一机构，不归一的话筛选下拉里会出现两个选项，**用户选任一个都筛不全**（实测：选「空格版」只得 10 份，实际有 39 份） |
| R1′ | 顺带修 1 处明显笔误：`吉林省生态环境厅=、吉林省…` 多了一个等号 | 1 条记录 | 属录入笔误，不是业务信息 |
| R2 | **化学品子库回填主题标签「化学品」** | 130 份（占全库 21%） | 台账第二张表就叫「知识查询（化学品）」，**该表没有「知识领域」列**，导致 130 份标签全空。标签取自台账自身的子库划分，不是推断值 —— 回填后主题标签对全库 617 份 100% 覆盖，主题筛选不再漏掉五分之一的内容 |
| R3 | **重复内容标记**（不改数据） | 11 组、12 份副本 | 按 SHA-256 逐字节比对，这些文件内容完全相同，属同一份资料重复建档。**只标记不删除**：卡片打「另有相同副本」小标、详情页给出对方链接，是否撤下需业务方拍板 |

产出的留痕文件：

| 文件 | 内容 |
|---|---|
| `backend/data/meta/零废弃知识库-元数据-617份-清洗版-2026-10-10.json` | 清洗后的元数据（导入工具的唯一输入） |
| `backend/data/kb-duplicates.json` | 11 组重复内容（键 = 副本 id，值 = 建议保留件 id） |
| `zwp-data/clean_log.json` | 逐条改动留痕（哪条记录、改前、改后），要回退照着它反向改即可 |
| `backend/data/kb-index.json.pre-clean-2026-10-10.json` 等 | 清洗前的索引/快照原样备份 |

## 四、接口与代码变动

| 位置 | 变动 | 为什么 |
|---|---|---|
| `GET /api/overview`（新增） | 整库画像：总量/体积/机构数/主题与类型分布/年份分布/最新收录 | 首页与数据概览页要展示统计。让前端拉 617 条自己算，既慢（31 页）又每次重算，服务端算一次更省 |

## 五、前端体验：鼠标动态光追 + 晕染小圈

按要求新增了氛围层 `src/components/MouseGlow.vue`，三件事：

1. **光追**：鼠标处一束柔光跟随（四层：大光晕 → 中层亮芯 → 贴手光圈 → 滞后拖尾光圈），
   逐层用不同的缓动系数靠近鼠标，移动时有速度感；点击时泛出一圈水波。
2. **晕染小圈**：5 团大而模糊的色斑（绿 / 青 / 琥珀）在页面背后极缓慢漂移，并随鼠标产生视差。
3. **三条硬约束**（都写进组件注释了）：
   - 整层 `pointer-events:none` 且压在所有内容之下 —— 绝不挡点击、不遮文字；
   - 识别 `prefers-reduced-motion`（系统「减弱动态效果」）与触摸设备，命中就不跑动画，只留静态底纹；
   - 只改 `transform`（走合成层、不触发布局），页面切到后台立刻停 rAF，回来续上。

## 六、怎么跑 / 怎么复现

```bash
# 1) 起后端（本地资料模式：书架读 kb-index.json，原件在 backend/data/kb/）
cd backend && DOCS_SOURCE=local npm run dev     # http://localhost:4000

# 2) 起前端
npm run dev:frontend                            # http://localhost:5173

# 3) 质量关（提交前必须过）
npm run verify                                  # 两包 lint + typecheck，当前 0 报错
npm run build                                   # 前端构建；后端会顺带托管 dist，单端口即整站
```

数据重跑（换一批资料时）：

```bash
python zwp-data/fix_dataset.py        # 生成清洗版元数据（机构归一 + 标签回填 + 重复组）
cd backend && npm run ingest -- \
  --meta "data/meta/零废弃知识库-元数据-617份-清洗版-2026-10-10.json" \
  --pdf  "data/kb" --out "data/kb-index.json"
python zwp-data/mark_duplicates.py    # 把重复标记翻译成索引 id（必须在 ingest 之后跑）
```

## 七、待基金会拍板的 6 项（本次未动）

| # | 事项 | 现状 | 建议 |
|---|---|---|---|
| 1 | **12 份重复副本是否撤下** | 保留并标记 | 建议每条保留 1 份、撤下 11 份（可省 45.5 MB，也免去访客点开发现内容一样）。撤下即从 `kb-index.json` 移除对应条目，原件归档不删 |
| 2 | **机构名写法** | 仅归并了顿号/空格三组 | 另有 `UNEP / ICCM5` 与 `UNEP（联合国环境规划署）/ ICCM5`、若干九部门长串署名。长串要不要拆成「牵头机构 + 联合发布」需业务定 |
| 3 | **化学品子库的主题标签** | 统一回填为「化学品」 | 若希望细分（如「农药」「汞」「塑料添加剂」），需基金会给出领域对照 |
| 4 | **3 条无文件台账行** | 未入库 | 「"无废城市"建设试点实施方案编制指南」等 3 条有名称无文件，需补文件或从台账剔除 |
| 5 | **5 条「未上传」标记滞后** | 未改 | 台账标「否」但引擎里其实已有，建议回填为「是」 |
| 6 | **机构信息与联系方式的对外表述** | 页面留了占位块 | 「关于项目」页的机构简介、邮箱/电话/地址、合作申请流程属基金会对外口径，**未确认前不填写**（页面已明确标注为占位） |

另：**线上书架走哪个数据源**仍未定 —— 走 `local`（有原件、可预览下载）还是 `engine`（需先把新增的 12 份补传进 WeKnora，否则书架少 12 份）。当前本地验证用的是 `local`，617 份齐全。
