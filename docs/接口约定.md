## 二、前端调用自建后端（后端提供）

| 用途 | 方法 + 路径 | 归属 | 返回要点 |

| 资料详情 | `GET /api/docs/:id` | 韶茹 | 单份资料完整信息 |
| 在线预览 | `GET /api/docs/:id/preview` | 韶茹 | 可渲染的 PDF 内容 |

| 注册 | `POST /api/auth/register` | 月月 | 五字段，成功 201 |

| 当前用户 | `GET /api/auth/me` | 月月 | 用户信息（需带 token） |

| 健康检查 | `GET /health` | — | `{"ok":true}` |

### 资料列表的查询参数（`GET /api/docs`）

| 参数 | 说明 | 默认 |
|---|---|---|
| `type` | 知识类型筛选（**单值**，页面 tab 本身单选） | 空 |
| `org` | 发布机构筛选，**可重复传参多选** | 空 |
| `year` | 发布年份筛选，**可重复传参多选** | 空 |
| `tag` | 主题筛选，**可重复传参多选**（**单数 `tag`，不是 `topic`/`tags`**） | 空 |
| `q` | 关键词（匹配标题/文件名） | 空 |
| `page` | 页码，从 1 开始 | 1 |
| `pageSize` | 每页条数，**封顶 100** | 20 |
| `sort` | `year_desc`（默认） / `newest` | `year_desc` |

**多选传法（2026-10-07 定稿——老师要求书架页「机构/年份/主题」支持多选）：**

同一参数重复出现即多选，例：

```
GET /api/docs?type=政策法规&org=零萌公益&org=自然之友&year=2023&year=2024&tag=垃圾分类&tag=堆肥
```

- 同一维度内是**或**：机构 = 零萌公益 或 自然之友
- 不同维度之间是**且**：在机构基础上再叠加年份、主题
- `GET /api/docs/facets` 接受**与列表相同的筛选参数**，用于各维度计数时排除自身维度的选择（保证计数与实际筛选结果一致）
- **前端注意**：axios 默认把数组序列化成 `org[]=a&org[]=b`，必须配置 `paramsSerializer`（`arrayFormat: 'repeat'`）才能发出 `org=a&org=b`
- **后端注意**：Express 里单值时 `req.query.org` 是 string，多值时是 string[]，**必须归一化成数组**再处理，别只按数组写

**响应格式（必须一致）**

```json
{
  "total": 476,
  "page": 1,
  "pageSize": 20,
  "zeroResult": false,
  "items": [
    {
      "id": "k-1",
      "title": "咖啡渣堆肥指南",
      "org": "零萌公益",
      "year": 2023,
      "type": "案例工具",
      "tags": ["厨余处理", "垃圾分类"],
      "size": 1408332
    }
  ]
}
```

> **`zeroResult: true`** 表示搜索无结果，前端据此显示"没有匹配的资料 + 试试问 AI"。

### 筛选项（`GET /api/docs/facets`）

```json
{
  "types":  [{ "value": "政策法规", "count": 120 }],
  "orgs":   [{ "value": "零萌公益", "count": 18 }],
  "years":  [{ "value": "2023", "count": 42 }],
  "tags":   [{ "value": "垃圾分类", "count": 120 }]
}
```

> **重要**：下拉里显示的数量，必须和实际筛出来的条数**完全一致**。
> 本接口接受与列表**相同的筛选参数**（type/org/year/tag/q），每维度的计数要**排除该维度自身的已选项**（否则点选后计数会越点越少）。

## 三、资料字段名（前后端统一）

| 字段 | 含义 | 类型 |
|---|---|---|
| `id` | 唯一标识 | string |
| `title` | 标题 | string |
| `org` | 发布机构 | string |
| `year` | 发布年份 | number |
| `type` | 知识类型 | string |
| `tags` | 主题标签 | string[] |
| `size` | 文件大小（字节） | number |

**禁止**用 `name` / `organization` / `publishYear` 等同义别名。

---

## 四、用户字段（注册五字段）

| 字段 | 含义 | 校验 |
|---|---|---|
| `name` | 姓名 | 必填 |
| `org` | 机构 | 必填 |
| `occupation` | 职业 | 必填 |
| `topics` | 关注议题 | 必填（数组，可多选） |
| `phone` | 电话 | 必填、手机号格式、唯一 |
| `password` | 密码 | 8–72 位 |

## 五、后端调用引擎（内部用，前端不关心）

| 用途 | 引擎接口 |
|---|---|
| 文件列表 | `GET /api/v1/knowledge-bases/:id/files` |
| 混合检索 | `POST /api/v1/knowledge-bases/:id/hybrid-search?resource_urls=public` |
| 文档详情 | `GET /api/v1/knowledge/:id` |
| 在线预览 | `GET /api/v1/knowledge/:id/preview` |
| 下载原件 | `GET /api/v1/knowledge/:id/download` |
| 问答钥匙 | `POST /api/v1/embed/:channel_id/exchange` |

认证：请求头 `X-API-Key: <WEKNORA_API_KEY>`，地址从 `.env` 读 `WEKNORA_BASE_URL`。
