## 三、这次**没**合什么，以及为什么

| 未合项 | 原因 |
|---|---|
| `scripts/qa-*.js`、`scripts/audit-*.py`（8 个自查脚本） | 依赖 `puppeteer-core` / 新 npm 脚本；属于「工程化」第二批，单独评估，避免把测试工具链混进视觉改动 |
| 根 `package.json` 的 `format` / `verify:all` / `qa:*` 脚本、`.prettierignore`、prettier 依赖 | 同上；`format:check` 会要求全仓格式化（含别人正在改的文件），不能顺带开门 |
| `dae2365` 的 backend / data / lock 全量格式化 | 纯格式化噪音，改别人的文件，违反「只动自己的文件」 |
| `InsightsView.vue`（她新增的「数据概览」页，546 行） | 是**新增页面**，不属于视觉系统收口范围，需单独评审是否要这个页面 |
| 20 张 `docs/shots/*.png`、2 份交付记录、4 张任务卡 | 与她未合入的脚本 / npm 脚本 / InsightsView 强耦合（文档里直接写 `npm run qa:shots`、指向未合入页面），整份搬进来会对不上，留在原分支 |
| 页面级 `font-size` → 令牌替换（HomeView / ChatView / SiteNav / SiteFooter / DocCard / ChatBubble / AdminUsersView / AdminKnowledgeView / AdminStatsView） | 忽略空白后逐行核过：这些页面只有字号写法变化，无观感变化；与我们重写过的页面冲突大、风险大于收益，留第二批 |
